# Лаба 4 Проверка API через Bruno

Сделал продвинутый вариант. Основная работа - 16 HTTP-запросов в Bruno, по две проверки у каждого: статус и содержимое JSON. Проверил четыре эндпоинта, обычные данные и основные ошибки. До исправлений проходили 10 запросов из 16, после - все 16. Проверки: 21/32 до, 32/32 после.

## Как запустить сервер на этом компьютере

В PowerShell из корня `lab4-testing`:

```powershell
.\.venv\Scripts\python.exe testing\server.py
```

Сервер откроется на `http://localhost:8000`. Оставь терминал открытым. Остановить сервер можно Ctrl+C.

На другом компьютере сначала создай окружение и установи Flask:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r testing\requirements.txt
```

## Как открыть коллекцию в Bruno

1. Если настольного Bruno ещё нет, скачай его с https://www.usebruno.com/downloads.
2. В Bruno нажми Open Collection и выбери папку `testing/bruno/coffee-api`.
3. Выбери окружение `Local`. В нём `baseUrl = http://localhost:8000`.
4. Открой запрос и нажми Send, затем посмотри вкладку Tests. Или запусти коллекцию целиком через Runner.
5. У неправильных запросов ожидается 400: это успешный тест, если сервер правильно отклонил данные.

Для начала хватит четырёх примеров: `order-total.bru`, `08-most-expensive.bru`, `09-wifi-default.bru`, `13-receipt.bru`. Затем посмотри `04-order-negative.bru`: он должен получить 400 и сообщение error.

## Проверка из командной строки

Я проверил коллекцию через Bruno CLI 4.3.0. Он установлен отдельно от репозитория, глобальные настройки не менял. Если используешь обычную установку CLI, поставь `npm install -g @usebruno/cli`, затем из `testing/bruno/coffee-api`:

```sh
bru run --env Local --sandbox safe --reporter-json ../../reports/414791/after.json --reporter-html ../../reports/414791/after.html
```
