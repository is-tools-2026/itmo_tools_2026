# Лаба 4 Проверка API через Bruno

Продвинутый вариант: 16 HTTP-запросов в Bruno, по две проверки у каждого: статус и содержимое JSON. Проверяются четыре эндпоинта, обычные данные и ошибки ввода. До исправлений проходили 10 запросов из 16, после - все 16. Проверки: 21/32 до, 32/32 после.

## Запуск сервера

В PowerShell из корня репозитория:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r testing\requirements.txt
.\.venv\Scripts\python.exe testing\server.py
```

Если окружение уже создано и Flask установлен, достаточно последней команды. Сервер работает на `http://localhost:8000`. Терминал нужно оставить открытым; остановка — Ctrl+C.

## Как открыть коллекцию в Bruno

1. Если настольного Bruno ещё нет, скачай его с https://www.usebruno.com/downloads.
2. В Bruno нажми Open Collection и выбери папку `testing/bruno/coffee-api`.
3. Выбери окружение `Local`. В нём `baseUrl = http://localhost:8000`.
4. Открой запрос и нажми Send, затем посмотри вкладку Tests. Или запусти коллекцию целиком через Runner.
5. У неправильных запросов ожидается 400: это успешный тест, если сервер правильно отклонил данные.

## Проверка из командной строки

Для запуска через CLI: `npm install -g @usebruno/cli`. Затем из папки `testing/bruno/coffee-api`:

```sh
bru run --env Local --sandbox safe --reporter-json ../../reports/414791/after.json --reporter-html ../../reports/414791/after.html
```
