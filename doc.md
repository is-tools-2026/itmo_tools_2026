## Функции

### `make_tea(water_ml, sugar_spoons)`
Делает строку с описанием чая.

- `water_ml` (int): сколько воды, мл
- `sugar_spoons` (int): сколько ложек сахара
- Возвращает `str`

```python
make_tea(200, 2)  # 'Чай: 200 мл воды, 2 ложки сахара'
```

### `buy_products(money, price_per_item, items_count)`
Считает сдачу: `money - price_per_item * items_count`. Налоги не учитываются.

- `money` (int | float): сколько денег у покупателя
- `price_per_item` (int | float): цена одного товара
- `items_count` (int): сколько штук
- Возвращает число (сдачу) или строку `"Недостаточно денег"`

```python
buy_products(100, 10, 5)  # 50
buy_products(10, 10, 5)   # 'Недостаточно денег'
```

**Подвох:** результат бывает и числом, и строкой, поэтому перед использованием его надо проверять.

### `check_weekend(day)`
Говорит, выходной ли день. Понимает `сб`, `вс`, `суббота`, `воскресенье`, регистр не важен.

- `day` (str)
- Возвращает `bool`

```python
check_weekend("Суббота")  # True
check_weekend("пн")       # False
```

**Подвох:** английские названия и строки с лишними пробелами дадут `False`.

### `even_odd(num)`
Проверяет, чётное ли число.

- `num` (int)
- Возвращает `bool`: `True`, если чётное

```python
even_odd(4)  # True
even_odd(7)  # False
```

### `multiplies_of_3(start, stop, step=1)`
Собирает числа, которые делятся на 3, из диапазона как в `range`.

- `start` (int): откуда начинаем
- `stop` (int): где заканчиваем (само число не входит)
- `step` (int): шаг, по умолчанию 1
- Возвращает `list[int]`

```python
multiplies_of_3(0, 10)     # [0, 3, 6, 9]
multiplies_of_3(1, 20, 2)  # [3, 9, 15]
```

**Подвохи:**
- если `step=0`, будет ошибка `ValueError`;
- ноль делится на 3, поэтому при `start=0` он попадёт в результат.

### `textmood_score(text, positive_words, negative_words)`
Оценивает настроение текста. Хорошее слово даёт +1, плохое даёт −1. Слово с `!` в конце умножает весь счёт на 1.5, слово с `?` умножает на 0.3. Итог округляется до одного знака.

- `text` (str): текст
- `positive_words` (list[str]): хорошие слова
- `negative_words` (list[str]): плохие слова
- Возвращает `int | float`

```python
textmood_score("I love Python!", ["love"], ["hate"])    # 1.5
textmood_score("do you love it?", ["love"], ["hate"])   # 0.3
textmood_score("I hate it", ["love"], ["hate"])         # -1
```

**Подвохи:**
- умножается весь набранный счёт, а не только текущее слово;
- знаки препинания не убираются, поэтому `"love!"` не равно `"love"` и балл за него не даётся;
- слова в списках надо писать маленькими буквами.

### `number_to_binary(number, score=0)`
Пытается перевести число в двоичный вид.

- `number` (int): число; если оно 0 или меньше, вернётся `"0"`
- `score` (int): стартовое значение счётчика цифр, по умолчанию 0
- Возвращает `str`

```python
number_to_binary(10)      # '0101'  (правильно было бы '1010')
number_to_binary(10, 8)   # '1010'
number_to_binary(1024)    # '10000000000'
number_to_binary(0)       # '0'
```

**Подвох (баг):** биты собираются с конца, а развернуть их в правильный порядок функция догадывается только если `score` стал больше 10. При значении по умолчанию это числа от 1024. Для маленьких чисел ответ получается задом наперёд. Чинится одной строкой: всегда делать `bits.reverse()`. Я оставил как было, чтобы не менять чужую логику без согласования.
