Введение
Данный проект содержит набор учебных функций на языке Python. Каждая функция демонстрирует различные приёмы программирования: работу с условными операторами, циклами, строками, списками, а также базовые алгоритмы (например, перевод числа в двоичную систему). Все функции снабжены комментариями и примерами вызова.

Описание функций
1. make_tea
Описание:
Готовит чай, смешивая воду и сахар.

Аргументы:

water_ml (int): объём воды в миллилитрах.

sugar_spoons (int): количество ложек сахара.

Возвращает:

str: описание получившегося напитка.

Пример вызова:

python
>>> make_tea(200, 2)
'Чай: 200 мл воды, 2 ложки сахара'
2. buy_products
Описание:
Рассчитывает сдачу после покупки товаров. Если сумма покупки превышает имеющиеся деньги, возвращает сообщение об ошибке.

Аргументы:

money (float): количество имеющихся денег.

price_per_item (float): цена за одну единицу товара.

items_count (int): количество единиц товара.

Возвращает:

float: сумма сдачи, если денег достаточно.

str: сообщение "Недостаточно денег", если сумма покупки превышает деньги.

Пример вызова:

python
>>> buy_products(100, 10, 5)
50
>>> buy_products(30, 10, 5)
'Недостаточно денег'
3. is_weekend
Описание:
Определяет, является ли день недели выходным (суббота или воскресенье).

Аргументы:

day (str): название дня недели (например, "Суббота", "вс").

Возвращает:

bool: True, если день — суббота или воскресенье, иначе False.

Пример вызова:

python
>>> is_weekend("Суббота")
True
>>> is_weekend("Понедельник")
False
4. is_even
Описание:
Проверяет, является ли число чётным.

Аргументы:

number (int): целое число.

Возвращает:

bool: True, если число чётное, иначе False.

Пример вызова:

python
>>> is_even(4)
True
>>> is_even(7)
False
5. get_multiples_of_three
Описание:
Возвращает список чисел, кратных 3, в заданном диапазоне.

Аргументы:

start (int): начало диапазона.

end (int): конец диапазона (не включается).

step (int, optional): шаг перебора. По умолчанию 1.

Возвращает:

list[int]: список чисел, которые делятся на 3 без остатка.

Пример вызова:

python
>>> z(1, 10)
[3, 6, 9]
>>> z(0, 20, 2)
[0, 6, 12, 18]
6. sentiment_score
Описание:
Вычисляет оценку тональности текста на основе позитивных и негативных слов. Учитывает восклицательные и вопросительные знаки в конце слов.

Аргументы:

text (str): анализируемый текст.

positive_words (list[str]): список слов с положительной окраской.

negative_words (list[str]): список слов с отрицательной окраской.

Возвращает:

float: оценка тональности, округлённая до одного знака.

Пример вызова:

python
>>> sentiment_score("I love Python!", ["love", "like"], ["hate"])
1.5
>>> sentiment_score("I hate it?", ["love"], ["hate"])
-0.3
7. to_binary_string
Описание:
Преобразует целое число в его двоичное представление в виде строки.

Аргументы:

number (int): число для преобразования.

counter (int, optional): начальное значение счётчика итераций. По умолчанию 0.

Возвращает:

str: двоичная строка числа.

Пример вызова:

python
>>> to_binary_string(10)
'1010'
>>> to_binary_string(0)
'0'
