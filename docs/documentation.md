# Документация к `mysterious_file.py`

## Описание проекта

Файл `mysterious_file.py` содержит функции, оставшиеся от бывшего разработчика Дмитрия. В лабораторной работе №2 функции переименованы (логика не менялась), для каждой написан docstring и составлена эта документация.

Все примеры из документации проверены командой:

```bash
python3 -m doctest mysterious_file.py
```

> Примечание: под каждой функцией в файле стоит `print(...)`, поэтому при импорте файла эти строки тоже выполняются.

## Функции

### `make_tea(water_ml, sugar_spoons)`

Описание: готовит чай, возвращает строку с описанием напитка (функция-пример из задания).

| Параметр | Тип | Описание |
|----------|-----|----------|
| `water_ml` | `int` | объём воды, мл |
| `sugar_spoons` | `int` | количество ложек сахара |

Возвращает `str`.

Пример вызова

```python
make_tea(200, 2)  # 'Чай: 200 мл воды, 2 ложки сахара'
```

### calculater(money, price_per_item, items_count)

Описание считает сдачу после покупки нескольких одинаковых товаров: `money - price_per_item * items_count`.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `money` | `int \| float` | сколько денег у покупателя |
| `price_per_item` | `int \| float` | цена одного товара |
| `items_count` | `int` | количество товаров |

Возвращает `int | float | str` — сдачу или строку `"Недостаточно денег"`.

Нюансы:
- возвращаемый тип разный (число или строка), результат нужно проверять перед арифметикой;
- если денег хватило ровно, вернётся `0`;
- налоги не учитываются.

Пример вызова

```python
calculater(100, 10, 5)  # 50
calculater(50, 10, 5)   # 0
calculater(20, 10, 5)   # 'Недостаточно денег'
```

### `check(day)`

Описание: проверяет, что день недели — суббота или воскресенье.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `day` | `str` | название дня по-русски: `"сб"`, `"вс"`, `"суббота"`, `"воскресенье"` (регистр не важен) |

Возвращает: `bool`.

Нюансы:
- пробелы по краям не убираются: `"суббота "` даёт `False`;
- английские названия не распознаются;
- если передать не строку, будет `AttributeError`;
- пятница выходным не считается (см. комментарий в коде).

Пример вызова:

```python
check("Суббота")      # True
check("вс")           # True
check("Понедельник")  # False
```

### `even(number)`

Описание: проверяет, чётное ли число.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `number` | `int \| float` | проверяемое число |

Возвращает `bool` — `True`, если число делится на 2 без остатка.

Нюансы `0` и отрицательные чётные числа тоже считаются чётными.

Пример вызова:

```python
even(10)  # True
even(7)   # False
even(0)   # True
even(-4)  # True
```

### `multiples3(start, stop, step=1)`

**Описание:** возвращает числа из `range(start, stop, step)`, которые делятся на 3.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `start` | `int` | начало диапазона (включительно) |
| `stop` | `int` | конец диапазона (НЕ включается) |
| `step` | `int` | шаг, по умолчанию `1`, не может быть `0` |

Возвращает `list[int]` — числа, кратные 3 (пустой список, если таких нет).

Нюансы
- `0` делится на 3, поэтому попадает в результат;
- `step=0` вызывает `ValueError`, дробные числа — `TypeError`;
- если `start > stop`, а шаг положительный, результат пустой.

Пример вызова

```python
multiples3(1, 20)       # [3, 6, 9, 12, 15, 18]
multiples3(0, 20, 2)    # [0, 6, 12, 18]
multiples3(10, 0, -1)   # [9, 6, 3]
```

### `sentiment_score(text, good_words, bad_words)`

Описание: оценивает настроение текста. Слова обрабатываются слева направо: слово из `good_words` даёт `+1`, из `bad_words` даёт `-1`. Если слово заканчивается на `!`, весь накопленный счёт умножается на `1.5`; если на `?` — на `0.3`. Результат округляется до 1 знака.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `text` | `str` | анализируемый текст |
| `good_words` | `list[str]` | позитивные слова (нижний регистр) |
| `bad_words` | `list[str]` | негативные слова (нижний регистр) |

Возвращает: `int | float` — оценка (больше 0 позитив, меньше 0 негатив, 0 нейтрально).

Нюансы:
- `!` и `?` прилипают к слову, поэтому `"love!"` не совпадает с `"love"` из списка, но множитель срабатывает;
- множитель применяется ко всему накопленному счёту, поэтому важен порядок слов;
- для отрицательного счёта `!` усиливает негатив (`-1` -> `-1.5`);
- несколько `!` в одном слове считаются как один;
- слова в списках должны быть в нижнем регистре.

Пример вызова:

```python
good = ["love", "like"]
bad = ["hate", "dislike"]
sentiment_score("I love Python!", good, bad)   # 1.5
sentiment_score("I hate bugs", good, bad)      # -1
sentiment_score("Do you love it?", good, bad)  # 0.3
```

### `bin(number, counter=0)`

Описание: переводит положительное целое число в двоичную запись (строку из `0` и `1`).

| Параметр | Тип | Описание |
|----------|-----|----------|
| `number` | `int` | число для перевода (ожидается > 0) |
| `counter` | `int` | начальное значение счётчика шагов, по умолчанию `0` |

Возвращает: `str` — двоичная запись; `"0"` для `number <= 0`.

Главный подвох: остатки собираются от младшего бита к старшему, а разворот делается только если `counter > 10` (то есть `counter` плюс количество бит больше 10). Поэтому для маленьких чисел (меньше 1024 при `counter=0`) результат записан **наоборот**: `bin(10)` даёт `"0101"`, а не `"1010"`. Для чисел от 1024 результат правильный. Логика намеренно не менялась.

Пример вызова:

```python
bin(10)       # '0101'   (правильно было бы '1010')
bin(6)        # '011'    (правильно было бы '110')
bin(1024)     # '10000000000'
bin(10, 20)   # '1010'   (counter > 10 включил разворот)
bin(0)        # '0'
```
