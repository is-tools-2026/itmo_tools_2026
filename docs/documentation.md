## Функции

### `make_tea(water_ml, sugar_spoons)`

Формирует строку с описанием чая.

- `water_ml` (`int`): объём воды, мл
- `sugar_spoons` (`int`): число ложек сахара
- **Возвращает** `str`

```python
make_tea(200, 2)   # 'Чай: 200 мл воды, 2 ложки сахара'
```

> Слово «ложки» не склоняется, для 1 или 5 ложек текст будет неверным.

### `buy_products(money, price_per_item, items_count)`

Считает сдачу после покупки `items_count` товаров по цене `price_per_item`.

- `money` (`int | float`): деньги покупателя
- `price_per_item` (`int | float`): цена одного товара
- `items_count` (`int`): количество товаров
- **Возвращает** `int | float` (сдачу) или `str` `"Недостаточно денег"`

```python
buy_products(100, 10, 5)   # 50
buy_products(100, 30, 5)   # 'Недостаточно денег'
```

> Налоги не учитываются. Если сумма точно равна деньгам, вернётся `0`.
> Тип результата разный, поэтому перед арифметикой проверяйте `isinstance(result, str)`.

### `is_weekend(day_name)`

Проверяет, выходной ли день.

- `day_name` (`str`): `"сб"`, `"вс"`, `"суббота"`, `"воскресенье"` в любом регистре
- **Возвращает** `bool`

```python
is_weekend("Суббота")   # True
is_weekend("пн")        # False
```

> Пробелы по краям не обрезаются (`" суббота"` даст `False`), английские названия не поддерживаются.

### `is_even(number)`

Проверяет чётность.

- `number` (`int`): число
- **Возвращает** `bool`

```python
is_even(10)   # True
is_even(7)    # False
```

### `filter_multiples_of_three(start, stop, step=1)`

Возвращает числа из `range(start, stop, step)`, которые делятся на 3.

- `start` (`int`): начало (включительно)
- `stop` (`int`): конец (не включается)
- `step` (`int`): шаг обхода, по умолчанию `1`; `0` вызовет `ValueError`
- **Возвращает** `list[int]`

```python
filter_multiples_of_three(1, 20)       # [3, 6, 9, 12, 15, 18]
filter_multiples_of_three(0, 10, 2)    # [0, 6]
filter_multiples_of_three(10, 0, -1)   # [9, 6, 3]
```

> `step` это шаг обхода, а не кратность. Число `0` считается кратным трём.

### `sentiment_score(text, positive_words, negative_words)`

Оценивает тональность текста. Слова идут по порядку: слово из позитивного
списка даёт `+1`, из негативного `-1`; затем, если слово кончается на `!`,
весь накопленный счёт умножается на `1.5`, если на `?`, то на `0.3`.

- `text` (`str`): текст
- `positive_words` (`Iterable[str]`): позитивные слова в нижнем регистре
- `negative_words` (`Iterable[str]`): негативные слова в нижнем регистре
- **Возвращает** `int | float` (счёт, округлён до 1 знака)

```python
sentiment_score("I love Python!", ["love", "like"], ["hate"])   # 1.5
sentiment_score("I hate this", ["love"], ["hate"])              # -1
sentiment_score("Do you like it?", ["like"], ["hate"])          # 0.3
```

> Подвохи:
> - множитель применяется ко **всему** счёту, а не к одному слову, порядок слов влияет на результат;
> - знаки препинания не отделяются: `"love!"` в словаре не найдётся, но множитель `1.5` сработает;
> - слово из обоих списков считается позитивным;
> - без множителей результат `int`, с ними `float`.

### `int_to_binary_string(number, initial_count=0)`

Переводит число в строку из `0` и `1` делением на 2. Остатки собираются от
младшего бита к старшему; счётчик `initial_count` растёт на 1 за каждый бит;
если итоговый счётчик больше 10, список разворачивается.

- `number` (`int`): число; значения `<= 0` дают `"0"`
- `initial_count` (`int`): начальное значение счётчика, по умолчанию `0`
- **Возвращает** `str`

```python
int_to_binary_string(10)     # '0101'  (в обычной записи 1010)
int_to_binary_string(6)      # '011'   (в обычной записи 110)
int_to_binary_string(1024)   # '10000000000'
int_to_binary_string(0)      # '0'
```

> **Главный подвох.** Для чисел меньше 1024 (при `initial_count=0`) биты идут
> в обратном порядке, и только для длинных чисел запись становится обычной.
> Для корректного результата используйте `bin(number)[2:]`.
> Комментарий в исходнике про падение при `x = 0` неверен: функция возвращает `"0"`.
