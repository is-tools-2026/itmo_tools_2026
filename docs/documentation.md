# Документация модуля mysterious_file.py

Функции исходного файла переименованы так, чтобы названия отражали суть.
Ниже — описание каждой функции с примерами.

## 1. calculate_change(money, price_per_item, items_count)

Вычисляет сдачу при покупке нескольких одинаковых товаров.
Если денег не хватает, возвращает строку с сообщением об ошибке.

- **Параметры:**
  - `money` (int): сумма денег у покупателя
  - `price_per_item` (int): цена одной единицы товара
  - `items_count` (int): количество покупаемых товаров
- **Возвращает:** `int | str` — величина сдачи либо `"Недостаточно денег"`

**Пример вызова:**
```python
>>> calculate_change(100, 10, 5)
50.0
>>> calculate_change(10, 10, 5)
'Недостаточно денег'
```

## 2. is_weekend(day)

Определяет, является ли переданный день недели выходным
(суббота или воскресенье), регистр не важен.

- **Параметры:**
  - `day` (str): название дня недели
- **Возвращает:** `bool` — True, если день выходной

**Пример вызова:**
```python
>>> is_weekend("Суббота")
True
>>> is_weekend("Понедельник")
False
```

## 3. is_even(number)

Проверяет, является ли целое число чётным.

- **Параметры:**
  - `number` (int): число для проверки
- **Возвращает:** `bool` — True, если число чётное

**Пример вызова:**
```python
>>> is_even(4)
True
>>> is_even(7)
False
```

## 4. multiples_of_three_in_range(start, end, step=1)

Возвращает список чисел из диапазона `[start, end)` с шагом `step`,
которые делятся на 3 без остатка.

- **Параметры:**
  - `start` (int): начало диапазона (включительно)
  - `end` (int): конец диапазона (исключительно)
  - `step` (int, optional): шаг обхода, по умолчанию 1
- **Возвращает:** `list[int]` — список чисел, кратных 3

**Пример вызова:**
```python
>>> multiples_of_three_in_range(0, 10, 1)
[0, 3, 6, 9]
>>> multiples_of_three_in_range(1, 20, 2)
[3, 9, 15]
```

## 5. analyze_sentiment(text, positive_words, negative_words)

Оценивает тональность текста: +1 за позитивное слово, −1 за негативное.
Восклицательный знак усиливает оценку в 1.5 раза,
вопросительный — уменьшает до 0.3 от текущей.

- **Параметры:**
  - `text` (str): анализируемый текст
  - `positive_words` (list[str]): список позитивных слов
  - `negative_words` (list[str]): список негативных слов
- **Возвращает:** `float` — оценка тональности, округлённая до 1 знака

**Пример вызова:**
```python
>>> analyze_sentiment("I love Python!", ["love", "like"], ["hate", "dislike"])
1.5
```

## 6. to_binary_reversed(number, threshold=0)

Преобразует неотрицательное целое число в двоичное представление в виде
строки. Если количество битов превышает 10, строка разворачивается.
Для нуля возвращает `"0"`.

- **Параметры:**
  - `number` (int): исходное неотрицательное число
  - `threshold` (int, optional): служебный счётчик битов, по умолчанию 0
- **Возвращает:** `str` — двоичное представление числа (или его реверс)

**Пример вызова:**
```python
>>> to_binary_reversed(10)
'0101'
>>> to_binary_reversed(2048)
'100000000000'
```
