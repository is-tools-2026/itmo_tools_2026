# Документация проекта

## Функции

### `buy_products(money, price_per_item, items_count)`

Считает остаток денег после покупки товаров.

**Параметры**

- `money` (`int`) — сумма денег у покупателя
- `price_per_item` (`int`) — цена одного товара
- `items_count` (`int`) — количество товаров

**Возвращает:** `int` — остаток денег (сдача), если денег хватило; `str` — сообщение `"Недостаточно денег"`, если суммы не хватает.

**Примеры**

```python
>>> buy_products(100, 10, 5)
50

>>> buy_products(20, 10, 5)
'Недостаточно денег'
```

### `is_weekend(day)`

Проверяет, является ли день недели выходным.

**Параметры**

- `day` (`str`) — название дня недели (сокращённое или полное, регистр не важен)

**Возвращает:** `bool` — `True`, если день выходной (сб, вс, суббота, воскресенье), иначе `False`.

**Примеры**

```python
>>> is_weekend("Суббота")
True

>>> is_weekend("пн")
False
```

### `chetnoe(number)`

Проверяет, является ли число чётным.

**Параметры**

- `number` (`int`) — число, которое проверяют

**Возвращает:** `bool` — `True`, если число чётное, иначе `False`.

**Примеры**

```python
>>> chetnoe(4)
True

>>> chetnoe(7)
False
```

### `numbers_divisible_by_3(start, stop, step=1)`

Возвращает числа из диапазона, которые делятся на 3 без остатка.

**Параметры**

- `start` (`int`) — начало диапазона
- `stop` (`int`) — конец диапазона
- `step` (`int`) — шаг перебора, по умолчанию `1`

**Возвращает:** `list[int]` — список чисел из диапазона, кратных 3.

**Примеры**

```python
>>> numbers_divisible_by_3(1, 10)
[3, 6, 9]

>>> numbers_divisible_by_3(0, 20, 5)
[0, 15]
```

### `sentiment_score(text, positive_words, negative_words)`

Определяет настроение текста по списку положительных и отрицательных слов.

**Параметры**

- `text` (`str`) — анализируемый текст
- `positive_words` (`list[str]`) — список слов, повышающих оценку
- `negative_words` (`list[str]`) — список слов, понижающих оценку

**Возвращает:** `float` — итоговая оценка настроения текста (округлённая до 1 знака). Восклицательный знак в конце слова усиливает эффект на x1.5, вопросительный наоборот ослабляет на x0.3.

**Примеры**

```python
>>> sentiment_score("I love Python!", ["love", "like"], ["hate", "dislike"])
1.5

>>> sentiment_score("I hate it", ["love", "like"], ["hate", "dislike"])
-1
```

### `to_binary(number, bit_count=0)`

Переводит число в двоичную запись.

**Параметры**

- `number` (`int`) — число для перевода
- `bit_count` (`int`) — счётчик количества бит, изначально `0`

**Возвращает:** `str` — двоичное представление числа (при малых числах порядок разрядов может быть перевёрнут). Для числа `0` возвращается строка `"0"`.

**Примеры**

```python
>>> to_binary(10)
'0101'

>>> to_binary(0)
'0'

>>> to_binary(1024)
'10000000000'
```
