# Документация mysterious_file.py

Функции взяты из файла, оставленного предыдущим разработчиком. Исходные имена функций и переменных были непонятными (`buy_products`, `check`, `h`, `z`, `t`, `p_w`, `n_w`, `s`, `x`, `y`, `z`) — переименованы в соответствии со смыслом выполняемых действий.

## calculate_change(money, price_per_item, items_count)

**Что делает.** Считает сдачу при покупке нескольких одинаковых товаров.

**Параметры.**
- `money` (int | float) — сумма денег у покупателя
- `price_per_item` (int | float) — цена одного товара
- `items_count` (int) — количество покупаемых товаров

**Возвращает.** Число `money - price_per_item * items_count`, если денег хватает, либо строку `"Недостаточно денег"`, если не хватает.

**Примеры.**
- `calculate_change(100, 10, 5)` → `50`
- `calculate_change(50, 10, 5)` → `0`
- `calculate_change(10, 10, 5)` → `"Недостаточно денег"`

**Замечания.** Функция возвращает значения разных типов (число или строка), поэтому вызывающий код должен проверять результат. Входные данные не проверяются: отрицательная цена даст бессмысленный результат.

## is_weekend(day)

**Что делает.** Проверяет, является ли день недели выходным (суббота или воскресенье).

**Параметры.** `day` (str) — строка с названием дня или сокращением. Регистр не важен.

**Возвращает.** `True`, если день — суббота или воскресенье, иначе `False`.

**Примеры.**
- `is_weekend("Суббота")` → `True`
- `is_weekend("ВС")` → `True`
- `is_weekend("Пятница")` → `False`

**Замечания.** Распознаются только четыре строки: `"сб"`, `"вс"`, `"суббота"`, `"воскресенье"`. Английские названия (`"Sunday"`) и строки с лишними пробелами дадут `False`. Если передать не строку — будет ошибка `AttributeError`.

## is_even(number)

**Что делает.** Проверяет, чётное ли число.

**Параметры.** `number` (int) — целое число.

**Возвращает.** `True`, если число делится на 2 без остатка, иначе `False`.

**Примеры.**
- `is_even(4)` → `True`
- `is_even(7)` → `False`
- `is_even(0)` → `True`
- `is_even(-3)` → `False`

**Замечания.** Для отрицательных чисел работает правильно.

## get_multiples_of_three(start, stop, step=1)

**Что делает.** Собирает список чисел, кратных 3, из последовательности `range(start, stop, step)`.

**Параметры.**
- `start` (int) — начало диапазона (включительно)
- `stop` (int) — конец диапазона (не включается)
- `step` (int) — шаг, по умолчанию 1

**Возвращает.** Список целых чисел, кратных 3.

**Примеры.**
- `get_multiples_of_three(1, 10)` → `[3, 6, 9]`
- `get_multiples_of_three(0, 10)` → `[0, 3, 6, 9]`
- `get_multiples_of_three(1, 10, 2)` → `[3, 9]`

**Замечания.** При шаге больше 1 проверяются только числа, которые выдаёт `range`, поэтому часть кратных тройке чисел пропускается (в последнем примере пропущено 6). Шаг `0` вызывает `ValueError`. Число 0 считается кратным 3.

## sentiment_score(text, positive_words, negative_words)

**Как считает.** Текст переводится в нижний регистр и делится по пробелам. Позитивное слово даёт +1, негативное −1. Если слово заканчивается на `!`, весь накопленный счёт умножается на 1.5, если на `?` — на 0.3. Итог округляется до одного знака.

**Возвращает.** Число — оценку настроения.

**Пример.** `sentiment_score("I love Python!", ["love", "like"], ["hate", "dislike"])` → `1.5`

**Обнаруженные проблемы.**
1. Множители применяются ко всему накопленному счёту, а не к текущему слову, поэтому порядок слов влияет на результат: `"love hello! hate"` даёт `0.5`, а `"hate love hello!"` — `0.0`.
2. Слово со знаком на конце (`"love!"`) не совпадает со словом из списка, поэтому не засчитывается: `"I love!"` → `0.0`.
3. Тип результата непостоянен: `"I love you"` даёт целое `1`, а с `!` или `?` — дробное число.

## to_binary(number, counter=0)

**Как работает.** Пока `number > 0`, в список добавляется остаток от деления на 2, затем число делится на 2 нацело, а `counter` растёт на 1. Остатки получаются от младшего бита к старшему. Разворот списка (`bits.reverse()`) выполняется либо при выходе из цикла, либо досрочно — если `counter` превысил 10.

**Примеры.**
- `to_binary(0)` → `"0"`
- `to_binary(1024)` → `"10000000000"` (верно)
- `to_binary(10)` → `"0101"` (неверно, должно быть `"1010"`)

**Обнаруженные ошибки.**
1. Разворот списка перед возвратом фактически не влияет на порядок битов для чисел меньше 1024 — результат остаётся в обратном порядке. Некоторые результаты оказываются верными случайно (`to_binary(5)` → `"101"`, потому что запись симметрична).
2. Так как `counter` — обычный параметр функции, его можно случайно передать извне и получить другой результат: `to_binary(10, 20)` → `"1010"` (случайно верный).
3. Для отрицательных чисел цикл не выполняется ни разу, функция возвращает `"0"`.
