# Документация проекта: Рефакторинг и документирование кода

## 1\. Описание функций

### Функция приготовления чая (`make_tea`)

* **Описание:** Готовит чай, смешивая воду и сахар.  
* **Аргументы:**  
  * `water_ml` (int): объём воды в миллилитрах  
  * `sugar_spoons` (int): количество ложек сахара  
* **Возвращает:**  
  * `str`: описание получившегося напитка  
* **Пример вызова:**  
    
  make\_tea(200, 2\)  \# Вернет: 'Чай: 200 мл воды, 2 ложки сахара'

### Функция расчета сдачи (`calculate_change`)

* **Описание:** Рассчитывает сдачу после покупки товара или возвращает сообщение о нехватке средств.  
* **Аргументы:**  
  * `money` (float): количество денег у покупателя  
  * `price_per_item` (float): цена за единицу товара  
  * `items_count` (int): количество единиц товара  
* **Возвращает:**  
  * `float | str`: оставшиеся деньги (сдача) или строка 'Недостаточно денег'  
* **Пример вызова:**  
    
  calculate\_change(100, 10, 5\)  \# Вернет: 50.0

### Функция проверки выходного дня (`is_weekend`)

* **Описание:** Проверяет, является ли переданный день недели выходным.  
* **Аргументы:**  
  * `day_name` (str): название или сокращение дня недели  
* **Возвращает:**  
  * `bool`: True, если день является выходным (суббота/воскресенье), иначе False  
* **Пример вызова:**  
    
  is\_weekend("Суббота")  \# Вернет: True

### Функция проверки на чётность (`is_even`)

* **Описание:** Проверяет, является ли число чётным.  
* **Аргументы:**  
  * `number` (int): проверяемое целое число 
* **Возвращает:**  
  * `bool`: True, если число чётное, иначе False  
* **Пример вызова:**  
    
  is\_even(4)  \# Вернет: True

### Функция фильтрации кратных трём (`filter_numbers_divisible_by_three`)

* **Описание:** Формирует список чисел в заданном диапазоне, которые делятся на 3 без остатка.  
* **Аргументы:**  
  * `start` (int): начало диапазона  
  * `end` (int): конец диапазона  
  * `step` (int): шаг инкремента  
* **Возвращает:**  
  * `list[int]`: список чисел, кратных трём  
* **Пример вызова:**  
    
  filter\_numbers\_divisible\_by\_three(1, 10\)  \# Вернет: \[3, 6, 9\]

### Функция оценки тональности (`calculate_sentiment_score`)

* **Описание:** Оценивает тональность текста на основе списков позитивных и негативных слов, учитывая знаки препинания.  
* **Аргументы:**  
  * `text` (str): анализируемый текст  
  * `positive_words` (list\[str\]): список позитивных ключевых слов  
  * `negative_words` (list\[str\]): список негативных ключевых слов  
* **Возвращает:**  
  * `float`: итоговая оценка тональности текста  
* **Пример вызова:**  
    
  calculate\_sentiment\_score("I love Python\!", \["love"\], \["hate"\])  \# Вернет: 1.5

### Функция конвертации в двоичную систему (`decimal_to_binary_string`)

* **Описание:** Конвертирует целое число в двоичную строку с учетом специфической логики разворота.  
* **Аргументы:**  
  * `decimal_number` (int): число в десятичной системе  
  * `iteration_counter` (int): счетчик итераций  
* **Возвращает:**  
  * `str`: двоичное представление числа в виде строки  
* **Пример вызова:**  
    
  decimal\_to\_binary\_string(10)  \# Вернет: '1010'
