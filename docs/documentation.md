# Документация проекта

В данном документе представлено описание основных функций файла `mysterious_file.py`.

## Описание функций

### 1. `make_tea(water_ml, sugar_spoons)`
Готовит чай, смешивая воду и сахар.
**Пример вызова:**
`make_tea(200, 2)` -> `'Чай: 200 мл воды, 2 ложки сахара'`

### 2. `calculate_change(money, price_per_item, items_count)`
Рассчитывает сдачу после покупки товаров.
**Пример вызова:**
`calculate_change(100, 10, 5)` -> `50`

### 3. `is_weekend(day_name)`
Проверяет, является ли переданный день недели выходным.
**Пример вызова:**
`is_weekend("Суббота")` -> `True`

### 4. `is_even(number)`
Проверяет переданное число на четность.
**Пример вызова:**
`is_even(4)` -> `True`

### 5. `get_multiples_of_three(start, end, step=1)`
Возвращает список чисел в заданном диапазоне, кратных трем.
**Пример вызова:**
`get_multiples_of_three(1, 10)` -> `[3, 6, 9]`

### 6. `sentiment_score(text, positive_words, negative_words)`
Анализирует текст и вычисляет его эмоциональный окрас.
**Пример вызова:**
`sentiment_score("I love Python!", ["love"], ["hate"])` -> `1.5`

### 7. `custom_to_binary(number, iterations=0)`
Преобразует десятичное число в строку с двоичным представлением (записанным в обратном порядке).
**Пример вызова:**
`custom_to_binary(10)` -> `'0101'`
