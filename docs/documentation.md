# Документация проекта

## Функции из mysterious_file.py

### make_tea(water_ml, sugar_spoons)
Готовит чай, смешивая воду и сахар.

- `water_ml` (int): объём воды в миллилитрах
- `sugar_spoons` (int): количество ложек сахара
- **Возвращает** `str`: описание напитка

```python
make_tea(200, 2)  # 'Чай: 200 мл воды, 2 ложки сахара'
```

### calculate_change(money, item_price, items_count)
Считает сдачу после покупки нескольких одинаковых товаров.

- `money` (int): сколько денег у покупателя
- `item_price` (int): цена одного товара
- `items_count` (int): количество товаров
- **Возвращает** `int | str`: сдачу, а если денег не хватает, то "Недостаточно денег"

```python
calculate_change(100, 10, 5)  # 50
```

### is_weekend(day_name)
Проверяет, является ли день недели выходным. Принимает полные названия и сокращения, регистр не важен.

- `day_name` (str): название дня, например "Суббота" или "вс"
- **Возвращает** `bool`: True для субботы и воскресенья

```python
is_weekend("Суббота")  # True
is_weekend("пн")       # False
```

### is_even(number)
Проверяет, является ли число чётным.

- `number` (int): проверяемое число
- **Возвращает** `bool`: True, если число делится на 2 без остатка

```python
is_even(4)  # True
is_even(7)  # False
```

### get_multiples_of_three(start, stop, step=1)
Возвращает числа из диапазона [start, stop) с шагом `step`, которые делятся на 3.

- `start` (int): начало диапазона (входит)
- `stop` (int): конец диапазона (не входит)
- `step` (int): шаг, по умолчанию 1
- **Возвращает** `list[int]`: числа, кратные трём

```python
get_multiples_of_three(0, 10)  # [0, 3, 6, 9]
```

### calculate_sentiment_score(text, positive_words, negative_words)
Оценивает настроение текста. Слово из положительных даёт +1, из отрицательных −1. Слово на "!" умножает счёт на 1.5, на "?" умножает на 0.3.

- `text` (str): анализируемый текст
- `positive_words` (list[str]): положительные слова
- `negative_words` (list[str]): отрицательные слова
- **Возвращает** `float`: оценка, округлённая до 1 знака

```python
calculate_sentiment_score("I love Python!", ["love"], ["hate"])  # 1.5
```

### convert_to_binary(number, iterations_count=0)
Переводит неотрицательное целое число в двоичную запись. Цифры собираются от младшего разряда к старшему и разворачиваются, только если шагов деления больше 10.

- `number` (int): неотрицательное число
- `iterations_count` (int): начальное значение счётчика шагов, по умолчанию 0
- **Возвращает** `str`: двоичные цифры строкой, для 0 возвращается "0"

```python
convert_to_binary(10)  # '0101'
```
