# Документация проекта

Описание функций из файла `mysterious_file.py`.

Файл достался проекту от предыдущего разработчика без документации: часть функций
имела неинформативные имена (`check`, `h`, `z`, `f`) и односимвольные переменные.
В рамках лабораторной работы №2 функции и переменные переименованы так, чтобы имя
отражало суть, а к каждой функции добавлен docstring с описанием параметров и
возвращаемого значения.

## Обзор

 `make_tea` - формирует описание напитка из объёма воды и количества сахара (`str`) `buy_products` - считает остаток денег после покупки (`int` или `str`) `weekend` - проверяет выходной ли день недели (`bool`) `even` - проверяет чётное ли число ( `bool`) `numbers_divisible_by_3`  отбирает из диапазона числа, кратные 3 (`list`) `sentiment_score` - оценивает настроение текста (`float`) `to_binary` - переводит число в двоичную запись (`str`)

## Функции

### `make_tea(water_ml, sugar_spoons)`

Формирует текстовое описание напитка по объёму воды и количеству ложек сахара.

**Параметры**

- `water_ml` (`int`) — объём воды в миллилитрах
- `sugar_spoons` (`int`) — количество ложек сахара

**Возвращает:** `str` — описание получившегося напитка.

**Пример**

```python
>>> make_tea(200, 2)
'Чай: 200 мл воды, 2 ложки сахара'
```

### `buy_products(money, price_per_item, items_count)`

Считает, сколько денег останется после покупки заданного количества товаров.
Стоимость покупки считается как цена за штуку, умноженная на количество.
Если денег не хватает, покупка не совершается.

**Параметры**

- `money` (`int`) — сумма денег у покупателя
- `price_per_item` (`int`) — цена одного товара
- `items_count` (`int`) — количество товаров

**Возвращает:** `int` — остаток денег, если суммы хватило; `str` — сообщение
`"Недостаточно денег"`, если стоимость покупки превысила имеющуюся сумму.
Тип возвращаемого значения зависит от исхода, это нужно учитывать при вызове.

**Примеры**

```python
>>> buy_products(100, 10, 5)
50

>>> buy_products(100, 30, 5)
'Недостаточно денег'
```

### `weekend(day)`

Проверяет относится ли переданный день недели к выходным. Название дня
приводится к нижнему регистру, поэтому регистр ввода значения не имеет.
Распознаются как полные названия, так и сокращения: `"сб"`, `"вс"`,
`"суббота"`, `"воскресенье"`.

**Параметры**

- `day` (`str`) — название дня недели

**Возвращает:** `bool` — `True`, если день выходной, иначе `False`.

**Примеры**

```python
>>> weekend("Суббота")
True

>>> weekend("Понедельник")
False
```

### `even(number)`

Проверяет чётность числа по остатку от деления на 2.

**Параметры**

- `number` (`int`) — проверяемое число

**Возвращает:** `bool` — `True`, если число чётное, иначе `False`.

**Примеры**

```python
>>> even(4)
True

>>> even(7)
False
```

### `numbers_divisible_by_3(start, stop, step=1)`

Перебирает числа в диапазоне и собирает те из них, которые делятся на 3 без
остатка. Параметры диапазона работают так же, как у встроенной функции
`range()`: значение `stop` в перебор не включается.

**Параметры**

- `start` (`int`) — начало диапазона
- `stop` (`int`) — конец диапазона, не включается
- `step` (`int`) — шаг перебора, стоит `1`

**Возвращает:** `list` — список чисел из диапазона, кратных 3. Если подходящих
чисел нет, возвращается пустой список.

**Примеры**

```python
>>> numbers_divisible_by_3(1, 10)
[3, 6, 9]

>>> numbers_divisible_by_3(0, 20, 2)
[0, 6, 12, 18]
```

### `sentiment_score(text, positive_words, negative_words)`

Оценивает эмоциональную окраску текста. Текст приводится к нижнему регистру и
разбивается на слова по пробелам. Каждое слово из списка положительных даёт
`+1` к оценке, каждое слово из списка отрицательных — `-1`.

Дополнительно учитывается знак в конце слова: восклицательный знак умножает
накопленную оценку на `1.5`, вопросительный — на `0.3`. Множитель применяется
ко всей накопленной сумме, а не к одному слову, поэтому порядок слов в тексте
влияет на результат.

**Параметры**

- `text` (`str`) — анализируемый текст
- `positive_words` (`list`) — слова, повышающие оценку
- `negative_words` (`list`) — слова, понижающие оценку

**Возвращает:** `float` — итоговая оценка, округлённая до одного знака после
запятой.

**Примеры**

```python
>>> sentiment_score("I love Python!", ["love", "like", "enjoy", "adore", "appreciate"], ["hate", "dislike", "detest", "antipathy"])
1.5

>>> sentiment_score("I hate bugs", ["love", "like"], ["hate", "dislike"])
-1
```

В первом примере слово `love` даёт `+1`, а следующее за ним `python!`
заканчивается восклицательным знаком и умножает накопленную оценку на `1.5`.

### `to_binary(number, bit_count=0)`

Переводит целое число в двоичную запись. Двоичные разряды вычисляются по
остатку от деления на 2, то есть накапливаются от младшего разряда к старшему.

**Параметры**

- `number` (`int`) — число для перевода
- `bit_count` (`int`) — счётчик разрядов, по умолчанию `0`

**Возвращает:** `str` — строку из нулей и единиц. Для числа `0` возвращается
строка `"0"`.

**Примеры**

```python
>>> to_binary(10)
'0101'

>>> to_binary(0)
'0'
```
