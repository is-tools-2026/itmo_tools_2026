# Документация к проекту

## Описание функций

### 1. **make_tea**
**Описание:** Готовит чай, смешивая воду и сахар.

**Параметры:**
1. **water_ml** (int): объём воды в миллилитрах
2. **sugar_spoons** (int): количество ложек сахара
**Возвращает:** str: описание получившегося напитка
**Пример вызова:**
```python
make_tea(200, 2)
```
**результат:** 'Чай: 200 мл воды, 2 ложки сахара'

---
### 2. **buy_products**
**Описание:** Указыает сумму сдачи, если денег недостаточно так и говорит.(без учета налогов)

**Параметры:**
1. **money** (int): сумма у покупателя
2. **price_per_item** (int): цена за единицу товара
3. **items_count** (int): количество едениц товара
**Возвращает:** **int**: сумма сдачи(в тех ед в которых был ввод)
                **str**: если недостаточно средств "Денег нет, но вы держитесь"
**Пример вызова:**
```python
buy_products(10, 1, 5)
```
**результат:** **5**

### 4. **chet**
**Описание:** проверка числа на четность

**Параметры:**
1. **number** (int): число для проверки

```python

```

---
### 5. **trotskiy**
**Описание:** собирает кратные трем элементы в диапазоне c шагом

**Параметры:**
1. **left_bord** (int): левая граница
2. **right_bord** (int): правая граница(выколота)
3. **step** (int): шаг с которым берутся числа для проверки
**Возвращает:** **list**: список подходящих эллементов
**Пример вызова:**
```python
trotskiy(1, 10, 1)
```
**результат:** **[3,6,9]**

---
## 6. **sentiment_score**
**Описание:** собирает кратные трем элементы в диапазоне c шагом

**Параметры:**
1. **text** (str): текст
2. **positivi_word** (list): список хороших слов
3. **negativi_word** (list): список плохих слов
**Возвращает:** **float**: критерий радости округленный до 1 знака после запятой
**Пример вызова:**
```python
sentiment_score("I love Python!", ["love", "like", "enjoy", "adore", "appreciate"], ["hate", "dislike", "detest", "antipathy"])
```
**результат:** **1.8**

---
### 7. **bin_revers**
**Описание:** переводит число в двоичную систему и разворачивает

**Параметры:**
1. **number** (int): исходное число
**Возвращает:** **int**: перведеное в двоичную и отзеркаленое исходное число
**Пример вызова:**
```python
bin_revers(14, y=0)
```
**результат:** 0111
