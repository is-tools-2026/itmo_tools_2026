# Документация mysterious_file.py

Файл содержит унаследованный код без документации. Ниже описано, что делает каждая функция, какие у неё параметры, что она возвращает и какие проблемы в ней обнаружены. Код не изменялся: описывается исходная версия файла.

## buy_products(money, price_per_item, items_count)

**Что делает.** Считает сдачу при покупке нескольких одинаковых товаров.

**Параметры.**
- `money` — сколько денег у покупателя;
- `price_per_item` — цена одного товара;
- `items_count` — сколько товаров покупается.

**Возвращает.** Число `money - price_per_item * items_count`, если денег хватает, или строку `"Недостаточно денег"`, если не хватает.

**Примеры.**
- `buy_products(100, 10, 5)` → `50`
- `buy_products(50, 10, 5)` → `0`
- `buy_products(10, 10, 5)` → `"Недостаточно денег"`

**Замечания.** Функция возвращает значения разных типов (число или строка), поэтому вызывающий код должен проверять результат. Входные данные не проверяются: отрицательная цена даст бессмысленный результат.

## check(d)

**Что делает.** Проверяет, является ли день недели выходным (суббота или воскресенье).

**Параметры.** `d` — строка с названием дня или сокращением. Регистр не важен.

**Возвращает.** `True`, если день — суббота или воскресенье, иначе `False`.

**Примеры.**
- `check("Суббота")` → `True`
- `check("ВС")` → `True`
- `check("Пятница")` → `False`

**Замечания.** Распознаются только четыре строки: `"сб"`, `"вс"`, `"суббота"`, `"воскресенье"`. Английские названия (`"Sunday"`) и строки с лишними пробелами дадут `False`. Если передать не строку, будет ошибка `AttributeError`. Имя `check` не отражает смысл функции.

## h(x)

**Что делает.** Проверяет, чётное ли число.

**Параметры.** `x` — целое число.

**Возвращает.** `True`, если `x` делится на 2 без остатка, иначе `False`.

**Примеры.**
- `h(4)` → `True`
- `h(7)` → `False`
- `h(0)` → `True`
- `h(-3)` → `False`

**Замечания.** Для отрицательных чисел работает правильно. Имя `h` ничего не говорит о смысле функции.

## z(a, b, c=1)

**Что делает.** Собирает список чисел, кратных 3, из последовательности `range(a, b, c)`.

**Параметры.**
- `a` — начало диапазона (включительно);
- `b` — конец диапазона (не включается);
- `c` — шаг, по умолчанию 1.

**Возвращает.** Список целых чисел, кратных 3.

**Примеры.**
- `z(1, 10)` → `[3, 6, 9]`
- `z(0, 10)` → `[0, 3, 6, 9]`
- `z(1, 10, 2)` → `[3, 9]`

**Замечания.** При шаге больше 1 проверяются только числа, которые выдаёт `range`, поэтому часть кратных тройке чисел пропускается (в последнем примере нет 6). Шаг `0` вызывает `ValueError`. Число 0 считается кратным 3.

## sentiment_score(t, p_w, n_w)

**Что делает.** Оценивает настроение текста по спискам позитивных и негативных слов.

**Параметры.**
- `t` — анализируемый текст;
- `p_w` — список позитивных слов;
- `n_w` — список негативных слов.

**Как считает.** Текст переводится в нижний регистр и делится по пробелам. Позитивное слово даёт +1, негативное −1. Если слово заканчивается на `!`, весь накопленный счёт умножается на 1.5, если на `?` — на 0.3. Итог округляется до одного знака.

**Возвращает.** Число — оценку настроения.

**Пример.** `sentiment_score("I love Python!", ["love", "like"], ["hate", "dislike"])` → `1.5`

**Обнаруженные проблемы.**
1. Множители применяются ко всему накопленному счёту, а не к текущему слову, поэтому порядок слов влияет на результат: `"love hello! hate"` даёт `0.5`, а `"hate love hello!"` — `0.0`.
2. Слово со знаком на конце (`"love!"`) не совпадает со словом из списка, поэтому не засчитывается: `"I love!"` → `0.0`.
3. Тип результата непостоянен: `"I love you"` даёт целое `1`, а с `!` или `?` — дробное число.
