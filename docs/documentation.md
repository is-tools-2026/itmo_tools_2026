## multiples_of_three_in_range

Бывшая `z`. Возвращает все числа, кратные 3, из диапазона `[start, stop)`.

| Параметр | Тип | Описание |
|---|---|---|
| `start` | int | начало диапазона (входит) |
| `stop` | int | конец диапазона (не входит) |

**Возвращает:** `list[int]`.

**Что исправлено:** в исходной функции был параметр `step`. При `step > 1` перебирались только числа, на которые попадал step, и часть кратных трём чисел терялась (для `(1, 10, 2)` возвращалось `[3, 9]` без 6). Параметр `step` удалён.

```python
multiples_of_three_in_range(1, 10)  # [3, 6, 9]
```

## sentiment_score

Оценивает настроение текста. Слово из списка позитивных даёт +1, из списка негативных -1. Слово, оканчивающееся на `!`, умножает накопленный счёт на 1.5, на `?` на 0.3. Итог округляется до одного знака.

| Параметр | Тип | Описание |
|---|---|---|
| `text` | str | анализируемый текст |
| `positive_words` | list[str] | позитивные слова (в нижнем регистре) |
| `negative_words` | list[str] | негативные слова (в нижнем регистре) |

**Возвращает:** `int | float`. Целое число, если множители не применялись, иначе дробное.

**Что исправлено:** знаки препинания не отбрасывались, поэтому слово `"love!"` не совпадало с `"love"` из списка и баллов не давало. Теперь при поиске в списках знаки `!?.,;:` по краям слова убираются (`word.strip('!?.,;:')`), а множители работают как раньше.


```python
sentiment_score("I love Python!", ["love"], ["hate"])  # 1.5
sentiment_score("love!", ["love"], ["hate"])           # 1.5 (раньше было 0)
sentiment_score("I hate bugs", ["love"], ["hate"])     # -1
```

## to_binary_string

Бывшая `f`. Переводит неотрицательное целое число в двоичную запись.

| Параметр | Тип | Описание |
|---|---|---|
| `number` | int | переводимое число |

**Возвращает:** `str` из символов "0" и "1".

**Что исправлено:** исходная функция собирала биты от младшего к старшему и разворачивала результат только если счётчик `y` превышал 10, поэтому `f(10)` возвращала `"0101"` вместо `"1010"`. Теперь результат разворачивается всегда, а ненужный параметр `y` удалён.

**Особенности:** для 0 и отрицательных чисел возвращается `"0"`.

```python
to_binary_string(10)  # '1010'
to_binary_string(5)   # '101'
to_binary_string(0)   # '0'
```
