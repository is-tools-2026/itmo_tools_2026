# Документация проекта



## 1. make_tea

Формирует строку с указанным объёмом воды и количеством ложек сахара. Служит примером оформления документации.

Аргументы:

- `water_ml` (`int`) — объём воды в миллилитрах.
- `sugar_spoons` (`int`) — количество ложек сахара.

Возвращает `str` — описание напитка.

Пример:

```python
make_tea(200, 2)
# 'Чай: 200 мл воды, 2 ложки сахара'
```

## 2. buy_products

Вычисляет стоимость покупки и возвращает сдачу. Если денег не хватает, возвращает строку `"Недостаточно денег"`.

Аргументы:

- `money` (`int | float`) — доступная сумма денег.
- `price_per_item` (`int | float`) — цена одной единицы товара.
- `items_count` (`int`) — предполагаемое количество товара.

Возвращает `int | float | str` — сдачу либо сообщение о недостатке денег.

Примеры:

```python
buy_products(100, 10, 5)
# 50

buy_products(40, 10, 5)
# 'Недостаточно денег'

buy_products(50, 10, 5)
# 0
```


## 3. is_weekend

Прежнее имя: `check`.

Проверяет, обозначает ли строка субботу или воскресенье. Распознаёт `"сб"`, `"вс"`, `"суббота"`, `"воскресенье"` без учёта регистра.

Аргумент:

- `day_name` (`str`) — название или сокращение дня недели.

Возвращает `bool` — `True` для распознанного выходного дня, иначе `False`.

Примеры:

```python
is_weekend("Суббота")
# True

is_weekend("пн")
# False

is_weekend(" суббота ")
# False
```


## 4. is_even

Прежнее имя: `h`.

Проверяет чётность целого числа по остатку от деления на 2.

Аргумент:

- `number` (`int`) — число для проверки.

Возвращает `bool` — `True`, если число чётное, иначе `False`.

Примеры:

```python
is_even(4)
# True

is_even(7)
# False

is_even(0)
# True

is_even(-4)
# True
```

Ноль считается чётным. Тип аргумента отдельно не проверяется.

## 5. multiples_of_three

Прежнее имя: `z`.

Перебирает числа из `range(start, stop, step)` и возвращает те, которые делятся на 3 без остатка.

Аргументы:

- `start` (`int`) — начало диапазона, включается в перебор.
- `stop` (`int`) — граница окончания диапазона, не включается в перебор.
- `step` (`int`) — шаг перебора, по умолчанию `1`.

Возвращает `list[int]` — числа, кратные трём, в порядке перебора.

Примеры:

```python
multiples_of_three(1, 10)
# [3, 6, 9]

multiples_of_three(0, 10, 2)
# [0, 6]

multiples_of_three(9, 0, -1)
# [9, 6, 3]

multiples_of_three(1, 3)
# []
```


## 6. sentiment_score

Вычисляет условную оценку настроения текста. Переводит текст в нижний регистр и разбивает его по пробельным символам.

Аргументы:

- `text` (`str`) — текст для анализа.
- `positive_words` (`list[str]`) — позитивные слова в нижнем регистре.
- `negative_words` (`list[str]`) — негативные слова в нижнем регистре.

Возвращает `int | float` — оценку, округлённую до одного знака после запятой.

Для каждого слова выполняются действия:

1. За совпадение с позитивным словом добавляется `1` балл; иначе за совпадение с негативным вычитается `1` балл.
2. Если слово заканчивается на `!`, вся накопленная оценка умножается на `1.5`.
3. Если слово заканчивается на `?`, вся накопленная оценка умножается на `0.3`.

Примеры:

```python
sentiment_score("love Python!", ["love"], ["hate"])
# 1.5

sentiment_score("hate", ["love"], ["hate"])
# -1

sentiment_score("love?", ["love"], ["hate"])
# 0.0
```


## 7. binary_digits

Прежнее имя: `f`.

Получает двоичные цифры числа последовательным вычислением остатка от деления на 2 и целочисленным делением на 2. Порядок результата зависит от счётчика.

Аргументы:

- `number` (`int`) — число для преобразования.
- `counter` (`int`) — начальное значение счётчика, по умолчанию `0`.

Возвращает `str` — строку двоичных цифр. Для нуля и отрицательных чисел возвращает `"0"`.

Цифры сначала записываются от младшей к старшей. За каждую полученную цифру счётчик увеличивается на `1`. Если итоговый счётчик больше `10`, цифры разворачиваются в привычный порядок от старшей к младшей.

Примеры:

```python
binary_digits(10)
# '0101'

binary_digits(10, 7)
# '1010'

binary_digits(0)
# '0'

binary_digits(-4)
# '0'
```
