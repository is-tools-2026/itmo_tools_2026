# Документация mysterious_file.py

Файл содержит унаследованный код без документации. Ниже описано, что делает каждая функция, какие у неё параметры, что она возвращает и какие проблемы в ней обнаружены. Код не изменялся: описывается исходная версия файла.

## buy_products(money, price_per_item, items_count)

Что делает. Считает сдачу при покупке нескольких одинаковых товаров.

Параметры.
- money — сколько денег у покупателя;
- price_per_item — цена одного товара;
- items_count — сколько товаров покупается.

Возвращает. Число money - price_per_item * items_count, если денег хватает, или строку "Недостаточно денег", если не хватает.

Примеры.
- buy_products(100, 10, 5) → 50
- buy_products(50, 10, 5) → 0
- buy_products(10, 10, 5) → "Недостаточно денег"

Замечания. Функция возвращает значения разных типов (число или строка), поэтому вызывающий код должен проверять результат. Входные данные не проверяются: отрицательная цена даст бессмысленный результат.
