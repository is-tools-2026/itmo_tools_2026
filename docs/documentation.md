# 1. `make_tea`

### Назначение

Функция формирует описание чая на основе количества воды и сахара.

### Параметры

| Параметр       | Тип   | Описание                 |
| -------------- | ----- | ------------------------ |
| `water_ml`     | `int` | Объём воды в миллилитрах |
| `sugar_spoons` | `int` | Количество ложек сахара  |

### Возвращаемое значение

`str` — строка с описанием приготовленного напитка.

### Пример

```python
make_tea(200, 2)
```

Результат:

```text
Чай: 200 мл воды, 2 ложки сахара
```

# 2. `buy_products`

### Назначение

Функция рассчитывает стоимость покупки нескольких одинаковых товаров и проверяет, достаточно ли денег для покупки.

Если денег недостаточно, функция возвращает сообщение об ошибке.

### Параметры

| Параметр         | Тип   | Описание                      |
| ---------------- | ----- | ----------------------------- |
| `money`          | `int` | Количество имеющихся денег    |
| `price_per_item` | `int` | Цена одного товара            |
| `items_count`    | `int` | Количество покупаемых товаров |

### Возвращаемое значение

`int | str`:

* `int` — сдача, если денег достаточно;
* `str` — сообщение `"Недостаточно денег"`, если денег недостаточно.

### Пример

```python
buy_products(100, 10, 5)
```

Расчёт:

```text
10 × 5 = 50
100 − 50 = 50
```

Результат:

```text
50
```

Пример недостаточного количества денег:

```python
buy_products(30, 10, 5)
```

Результат:

```text
Недостаточно денег
```

# 3. `is_weekend`

### Назначение

Функция проверяет, является ли переданный день недели выходным днём.

За выходные дни принимаются:

* `сб`;
* `вс`;
* `суббота`;
* `воскресенье`.

Проверка выполняется без учёта регистра букв.

### Параметры

| Параметр | Тип   | Описание            |
| -------- | ----- | ------------------- |
| `day`    | `str` | Название дня недели |

### Возвращаемое значение

`bool`:

* `True` — если день является выходным;
* `False` — если день не является выходным.

### Пример

```python
is_weekend("Суббота")
```

Результат:

```text
True
```

Другой пример:

```python
is_weekend("Понедельник")
```

Результат:

```text
False
```

# 4. `is_even`

### Назначение

Функция проверяет, является ли число чётным.

Для проверки используется остаток от деления числа на `2`.

Если остаток равен `0`, число является чётным.

### Параметры

| Параметр | Тип   | Описание                |
| -------- | ----- | ----------------------- |
| `number` | `int` | Проверяемое целое число |

### Возвращаемое значение

`bool`:

* `True` — число чётное;
* `False` — число нечётное.

### Пример

```python
is_even(10)
```

Результат:

```text
True
```

Пример:

```python
is_even(7)
```

Результат:

```text
False
```

# 5. `get_multiples_of_three`

### Назначение

Функция проходит по диапазону чисел от `start` до `stop` с указанным шагом и выбирает только числа, которые делятся на `3` без остатка.

Граница `stop` в диапазон не включается.

### Параметры

| Параметр | Тип   | Описание                     |
| -------- | ----- | ---------------------------- |
| `start`  | `int` | Начальное значение диапазона |
| `stop`   | `int` | Конечное значение диапазона  |
| `step`   | `int` | Шаг изменения числа          |

Параметр `step` по умолчанию равен `1`.

### Возвращаемое значение

`list[int]` — список чисел из диапазона, которые делятся на `3` без остатка.

### Пример

```python
get_multiples_of_three(1, 10)
```

Диапазон:

```text
1, 2, 3, 4, 5, 6, 7, 8, 9
```

Числа, кратные трём:

```text
3, 6, 9
```

Результат:

```python
[3, 6, 9]
```

Другой пример:

```python
get_multiples_of_three(1, 10, 2)
```

Проверяемые числа:

```text
1, 3, 5, 7, 9
```

Результат:

```python
[3, 9]
```

# 6. `calculate_sentiment_score`

### Назначение

Функция рассчитывает числовую оценку настроения текста на основе списков положительных и отрицательных слов.

Алгоритм:

1. Текст переводится в нижний регистр.
2. Текст разделяется на отдельные слова.
3. За положительное слово добавляется `1`.
4. За отрицательное слово вычитается `1`.
5. Если слово заканчивается на `!`, текущая оценка умножается на `1.5`.
6. Если слово заканчивается на `?`, текущая оценка умножается на `0.3`.
7. Результат округляется до одного знака после запятой.

### Параметры

| Параметр         | Тип         | Описание                  |
| ---------------- | ----------- | ------------------------- |
| `text`           | `str`       | Анализируемый текст       |
| `positive_words` | `list[str]` | Список положительных слов |
| `negative_words` | `list[str]` | Список отрицательных слов |

### Возвращаемое значение

`float` — числовая оценка настроения текста.

### Пример

```python
calculate_sentiment_score(
    "I love Python!",
    ["love", "like", "enjoy", "adore", "appreciate"],
    ["hate", "dislike", "detest", "antipathy"]
)
```

Результат:

```text
1.5
```

Положительное слово `love` добавляет `1`, а знак `!` увеличивает результат:

```text
1 × 1.5 = 1.5
```

# 7. `convert_to_binary`

### Назначение

Функция преобразует целое число в последовательность двоичных цифр.

Внутри функции используется последовательное деление числа на `2` с сохранением остатков.

Полученные остатки записываются в список, после чего объединяются в строку.

Если количество обработанных цифр превышает `10`, список разворачивается.

### Параметры

| Параметр      | Тип   | Описание                                    |
| ------------- | ----- | ------------------------------------------- |
| `number`      | `int` | Число, которое необходимо преобразовать     |
| `digit_count` | `int` | Счётчик обработанных цифр, по умолчанию `0` |

### Возвращаемое значение

`str` — строковое представление результата преобразования.

Если переданное число равно `0`, функция возвращает строку `"0"`.

### Пример

```python
convert_to_binary(10)
```

Результат работы функции:

```text
0101
```

Для числа `10` выполняется последовательное деление:

```text
10 % 2 = 0
5 % 2 = 1
2 % 2 = 0
1 % 2 = 1
```

Полученные остатки:

```text
[0, 1, 0, 1]
```

Так как количество цифр не превышает `10`, список не разворачивается.

Результат:

```text
0101
```
