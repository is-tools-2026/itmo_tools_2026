# Документация
## Описание
Файл содержит документацию функций из файла mysterious_file.py. 
Для каждой функции даны:
- Описание действия функции
- Параметры и их типы
- Возвращаемые значения и их типы
- Примеры действия и результат
## 1. make_tea
### Что делает функция
Описывает чай по заданным параметрам
### Параметры
| Параметр | Тип | Описание |
| ----------- | ----------- | ----------- |
| water_ml | int | Объем воды в мл |
| sugar_spoons | int | Количество ложек сахара |
### Возвращаемые значения
str - описание получившегося напитка
### Пример действия
```
make_tea(200, 2) 
```
**Результат**  
Чай: 200 мл воды, 2 ложки сахара
## 2. buy_products
### Что делает функция
Проверяет, хватает ли денег на покупку товаров и возвращает сдачу или сообщение о недостатке средств.
### Параметры
| Параметр | Тип | Описание |
| ----------- | ----------- | ----------- |
| money | int | Сумма для покупки |
| price_per_item | int | Цена за товар |
| item_counts | int | Количество покупаемых товаров |
### Возвращаемые значения
str - Сообщение о недостатке денег  
int - Сдача после покупки
### Пример действия
```
buy_products(100, 10, 5) 
```
**Результат**  
50  
```
buy_products(100, 20, 6)  
```
**Результат**  
Недостаточно денег

## 5. multiples_of_three
### Что делает функция
Создает список чисел от first до last(не включая) с шагом step, которые делятся на 3.
### Параметры
| Параметр | Тип | Описание |
| ----------- | ----------- | ----------- |
| first | int | Начальное число |
| last | int | Конечное число |
| step | int | Шаг между числами, по умолчанию равен 1 |
### Возвращаемые значения
list - Список чисел, делящихся на 3
### Пример действия
```
multiples_of_three(1, 30)
```
**Результат**  
[3, 6, 9, 12, 15, 18, 21, 24, 27]
```
multiples_of_three(1, 30, 2)
```
**Результат**  
[3, 9, 15, 21, 27]
## 6. sentiment_score
### Что делает функция
Определяет настроение текста по количеству позитивных и негативных слов и учитывает восклицательные и вопросительные знаки.
### Параметры
| Параметр | Тип | Описание |
| ----------- | ----------- | ----------- |
| text | str | Текст для анализа |
| positive_words | list | Список позитивных слов |
| negative_words | list | Список негативных слов |
### Возвращаемые значения
float - Оценка настроения текста, округленная до одного знака после запятой
### Пример действия 
```
sentiment_score("I love Python!", ["love", "like", "enjoy", "adore", "appreciate"], ["hate", "dislike", "detest", "antipathy"])
```
**Результат**  
1.5
```
sentiment_score("I hate alcohol?", ["love", "like", "enjoy", "adore", "appreciate"], ["hate", "dislike", "detest", "antipathy"])
```
**Результат**  
-0.3
## 7. int_to_binary
### Что делает функция
Переводит число из десятичной системы счисления в двоичную, если число состоит более чем из 10 разрядов в двоичной системе, в противном случае после перевода выводит число наоборот.
### Параметры
| Параметр | Тип | Описание |
| ----------- | ----------- | ----------- |
| number | int | Число в десятичной системе счисления |
| count | int | счетчик разрядов числа в двоичной системе |
### Возвращаемые значения
str - строковое число в двоичной системе
### Пример действия
```
int_to_binary(10)
```
**Результат**  
0101
```
int_to_binary(10000)
```
**Результат**  
10011100010000
