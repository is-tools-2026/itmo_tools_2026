## Описание функций

### 1. Функция `make_tea(water_ml, sugar_spoons)`

**Назначение:** формирует строку с описанием напитка на основе указанного объёма воды и количества ложек сахара.

**Параметры:**
- `water_ml` (int) — объём воды в миллилитрах.
- `sugar_spoons` (int) — количество ложек сахара.

**Возвращаемое значение:**
- `str` — строка с описанием получившегося напитка.

**Пример использования:**

```python
make_tea(200, 2)
# Результат: 'Чай: 200 мл воды, 2 ложки сахара'
```

**Особенности:** функция не производит вычислений и не изменяет переданные значения. Результат формируется с помощью форматированной строки.



### 2. Функция `buy_products(money, price_per_item, items_count)`

**Назначение:** рассчитывает сумму сдачи после покупки заданного количества товаров.

**Параметры:**
- `money` (int | float) — сумма денег покупателя.
- `price_per_item` (int | float) — стоимость одного товара.
- `items_count` (int) — количество приобретаемых товаров.

**Возвращаемое значение:**
- `int | float` — сумма сдачи, если денег достаточно.
- `str` — сообщение `"Недостаточно денег"`, если стоимость покупки превышает имеющуюся сумму.

**Примеры использования:**

```python
buy_products(100, 10, 5)
# Результат: 50

buy_products(20, 10, 5)
# Результат: 'Недостаточно денег'
```

**Особенности:** общая стоимость покупки вычисляется умножением цены одного товара на количество товаров. Если стоимость превышает сумму денег покупателя, функция возвращает сообщение о недостатке средств. В противном случае возвращается разница между имеющейся суммой и стоимостью покупки.



### 3. Функция `is_weekend(day)`

**Назначение:** проверяет, является ли указанный день недели выходным.

**Параметры:**
- `day` (str) — название дня недели или его сокращение на русском языке.

**Возвращаемое значение:**
- `bool` — `True`, если день является субботой или воскресеньем, иначе `False`.

**Примеры использования:**

```python
is_weekend("Суббота")
# Результат: True

is_weekend("понедельник")
# Результат: False

is_weekend("вс")
# Результат: True
```

**Особенности:** функция переводит переданную строку в нижний регистр с помощью метода `lower()`, после чего проверяет её наличие в списке `["сб", "вс", "суббота", "воскресенье"]`. Функция распознаёт как полные названия выходных дней, так и их сокращения.



### 4. Функция `is_even(number)`

**Назначение:** проверяет, является ли переданное целое число чётным.

**Параметры:**
- `number` (int) — целое число, которое необходимо проверить на чётность.

**Возвращаемое значение:**
- `bool` — `True`, если число чётное, иначе `False`.

**Примеры использования:**

```python
is_even(4)
# Результат: True

is_even(7)
# Результат: False

is_even(0)
# Результат: True
```

**Особенности:** функция использует оператор `%` для вычисления остатка от деления числа на 2.
Если остаток равен нулю, число является чётным и функция возвращает `True`. В противном случае возвращается `False`. Функция также корректно обрабатывает ноль и отрицательные целые числа.



### 5. Функция `find_multiples_of_three(start, stop, step=1)`

**Назначение:** возвращает список чисел, кратных трём, из заданного диапазона.

**Параметры:**
- `start` (int) — начальное значение диапазона.
- `stop` (int) — конечная граница диапазона, которая не включается в перебор.
- `step` (int) — шаг перебора, по умолчанию равен 1.

**Возвращаемое значение:**
- `list[int]` — список чисел, которые делятся на 3 без остатка.

**Примеры использования:**

```python
find_multiples_of_three(1, 10)
# Результат: [3, 6, 9]

find_multiples_of_three(3, 15, 3)
# Результат: [3, 6, 9, 12]

find_multiples_of_three(1, 3)
# Результат: []
```

**Особенности:** функция использует `range(start, stop, step)` для перебора чисел.
Каждое число проверяется с помощью условия `number % 3 == 0`. Если условие выполняется, число добавляется в результирующий список.
Значение `step` может быть отрицательным для обратного перебора, но не может равняться нулю. При `step=0` возникает ошибка `ValueError`.



### 6. Функция `sentiment_score(text, positive_words, negative_words)`

**Назначение:** вычисляет числовую оценку эмоциональной окраски текста на основе заданных списков положительных и отрицательных слов.

**Параметры:**
- `text` (str) — текст для анализа.
- `positive_words` (list[str]) — список положительных слов.
- `negative_words` (list[str]) — список отрицательных слов.

**Возвращаемое значение:**
- `int | float` — итоговая оценка эмоциональной окраски текста, округлённая до одного знака после запятой.

**Примеры использования:**

```python
sentiment_score("love", ["love"], ["hate"])
# Результат: 1

sentiment_score("hate", ["love"], ["hate"])
# Результат: -1

sentiment_score("love hate", ["love"], ["hate"])
# Результат: 0
```

**Особенности работы:**
Функция переводит текст в нижний регистр и разбивает его на слова с помощью `split()`.
За каждое положительное слово прибавляется 1 балл, за отрицательное вычитается 1 балл.
Если слово заканчивается на `!`, текущая оценка умножается на 1.5, а если на `?` — на 0.3.
При этом знаки препинания не удаляются из слов. Например, `love!` не совпадает с `love` в списке положительных слов. Итоговое значение округляется с помощью `round(score, 1)`.



### 7. Функция `number_to_binary(number, counter=0)`

**Назначение:** формирует строку из двоичных цифр заданного целого числа.

**Параметры:**
- `number` (int) — неотрицательное целое число для преобразования.
- `counter` (int) — начальное значение счётчика итераций, по умолчанию 0.

**Возвращаемое значение:**
- `str` — строка из двоичных цифр числа. Для нуля возвращается строка `"0"`.

**Примеры использования:**

```python
number_to_binary(10)
# Результат: '0101'

number_to_binary(10, 7)
# Результат: '1010'

number_to_binary(0)
# Результат: '0'
```

**Особенности работы:**

Функция последовательно делит число на 2 и сохраняет остатки от деления в список `binary_digits`. На каждой итерации значение счётчика `counter` увеличивается на 1.
После завершения цикла, если итоговое значение `counter` превышает 10, список двоичных цифр разворачивается с помощью `reverse()`.
Если значение счётчика не превышает 10, цифры остаются в обратном порядке.
Например, при вызове `number_to_binary(10)` результатом будет `'0101'`, хотя стандартная двоичная запись числа 10 — `'1010'`. Таким образом, функция сохраняет особенности исходного алгоритма и не всегда возвращает стандартное двоичное представление числа.
