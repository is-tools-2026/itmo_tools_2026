# Документация проекта: Модуль Mysterious File

## Описание функций

### 1. `make_tea`
Готовит чай, смешивая воду и сахар.
* **Args:**
  * `water_ml` (int): объём воды в миллилитрах.
  * `sugar_spoons` (int): количество ложек сахара.
* **Returns:**
  * `str`: описание получившегося напитка.
* **Пример вызова:**
  ```python
  make_tea(200, 2)
  # Результат: 'Чай: 200 мл воды, 2 ложки сахара'
  ```

### 2. `buy_products`
Вычисляет сдачу после покупки определенного количества товаров.
* **Args:**
  * `money` (int or float): количество денег у покупателя.
  * `price_per_item` (int or float): цена за одну единицу товара.
  * `items_count` (int or float): количество приобретаемых единиц товара или вес (для товаров наразновес).
* **Returns:**
  * `int or float or str`: сдача или строка "Недостаточно денег", если общая стоимость превышает бюджет.
* **Пример вызова:**
  ```python
  buy_products(100, 10, 5)
  # Результат: 50
  ```

### 3. `is_weekend`
Проверяет, введенный день выходной или нет.
* **Args:**
  * `day_name` (str): название дня недели (в короткой или полной форме) — *в коде передается через аргумент `d`*.
* **Returns:**
  * `bool`: True, если день выходной, иначе False.
* **Пример вызова:**
  ```python
  is_weekend("Суббота")
  # Результат: True
  ```

### 4. `is_even`
Проверяет четность числа.
* **Args:**
  * `number` (int): число, четность которого проверяется.
* **Returns:**
  * `bool`: 1, если четное, 0, если нечетное (согласно Docstring).
* **Пример вызова:**
  ```python
  is_even(67)
  # Результат: 0
  ```

### 5. `are_divisible_by_3_in_range`
Находит все числа, кратные 3-м в заданном диапазоне с шагом (по умолчанию 1).
* **Args:**
  * `start` (int): начальное значение диапазона (включая).
  * `end` (int): конечное значение диапазона (не включая).
  * `step` (int) (optional): шаг проверки. По умолчанию равен 1.
* **Returns:**
  * `list`: список целых чисел, которые делятся на 3 без остатка.
* **Пример вызова:**
  ```python
  are_divisible_by_3_in_range(0, 9)
  # Результат: [0, 3, 6]
  ```

### 6. `sentiment_score`
Вычисляет насколько текст был радостным/грустным, сверяясь с позитивным и негативным списком слов и учитывая знаки препинания (? или !).
* **Args:**
  * `text` (str): текст, который надо оценить.
  * `list_of_positive_words` (list[str]): список слов, которые считаются позитивными.
  * `list_of_negative_words` (list[str]): список слов, которые считаются негативными (может пересекаться с позитивным списком, но тогда это слово не влияет).
* **Returns:**
  * `int`: оценка позитивности текста (округленная до десятых).
* **Пример вызова:**
  ```python
  sentiment_score("Хочу пельмени!", ["пельмени", "пицца", "котлетки", "пюрешка"], ["сюрстрёминг", "голод"])
  # Результат: 1.5
  ```

### 7. `convert_to_binary_str`
Переводит десятичную запись числа в двоичную. Запись перевернута, если число меньше 2 в степени (10 - (второй аргумент)).
* **Args:**
  * `dec_number` (int): число для перевода в двоичную систему.
  * `defoult_counter` (int) (optional): аргумент, определяющий, до какого числа запись будет перевернутой.
* **Returns:**
  * `str`: запись числа в bin системе.
* **Пример вызова:**
  ```python
  convert_to_binary_str(2**5-2, 5)
  # Результат: "01111"
  ```
