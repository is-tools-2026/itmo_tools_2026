## Функция 1

### `buy_products(money, price_per_item, items_count)`

- Функция сравнивает баланс со стоимостью покупки и возвращает сдачу.
- Если баланса не хватает - выводит сообщение о нехватке средств.

### Параметры

1. `money` (`int`): Баланс на счету
2. `price_per_item` (`int`): Стоимость одного предмета
3. `items_count` (`int`): Количество предметов

### Возвращает:

1. `str`:
   - `"Недостаточно денег"` - если у нас недостаточно средств
2. `int`:
   - возвращает сдачу, если денег достаточно

### Примеры:

```python
buy_products(200, 50, 5)  # "Недостаточно денег"
```

```python
buy_products(777, 2, 111)  # 555
```

## Функция 2

### `daycheck(day)`

- Проверяет, выходной ли сегодня день.

### Параметры

1. `day` (`str`): день недели

### Возвращает:

1. `bool`:
   - `True` - если день является выходным
   - `False` - если день не является выходным

### Примеры:

```python
daycheck("Понедельник")  # False
```

```python
daycheck("сб")  # True
```

## Функция 3

### `evencheck(x)`

- Проверяет, чётное число или же нет.

### Параметры

1. `x` (`int`): число для проверки

### Возвращает:

1. `bool`:
   - `True` - если число чётное
   - `False` - если число нечётное

### Примеры:

```python
evencheck(111111)  # False
```

```python
evencheck(100010001111000101000110001000010)  # True
```

## Функция 4

### `checktrio(a, b, c=1)`

- Проверяет последовательность чисел на делимость на три.

### Параметры

1. `a` (`int`): начало последовательности
2. `b` (`int`): конец последовательности
3. `c` (`int`, по умолчанию `1`): шаг последовательности

### Возвращает:

1. `list`:
   - список выявленных чисел, кратных трём

### Примеры:

```python
checktrio(1, 12, c=1)  # [3, 6, 9]
```

## Функция 5

### `sentiment_score(text, good_wd, bad_wd)`

- Алгоритм, который понимает эмоции, вложенные в текст.

### Параметры

1. `text` (`str`): заданный текст
2. `good_wd` (`list`): список хороших слов
3. `bad_wd` (`list`): список негативных слов

### Возвращает:

1. `float`:
   - коэффициент эмоциональности текста, округлённый до одного знака после запятой

### Примеры:

```python
sentiment_score(
    "Всем привет! Я очень хороший и добрый человек. Наверное?",
    ["добрый", "хороший", "весёлый"],
    ["злой", "плохой"]
)  # 0.6
```

## Функция 6

### `binary(x, y=0)`

- Функция, что переводит число в двоичную систему счисления.

### Параметры

1. `x` (`int`): число для перевода
2. `y` (`int`, по умолчанию `0`): счётчик

### Возвращает:

1. `str`:
   - число в двоичной системе счисления
   - `"0"` - если число равно нулю

### Примеры:

```python
binary(123)  # "1111011"
```

```python
binary(10)  # "1010"
```
