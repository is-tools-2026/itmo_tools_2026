# Документация по функциям

Описание функций из файла mysterious_file.py с примерами вызова.

# Функции

## change(money, price_per_item, items_count)
Считает сдачу после покупки одинаковых товаров.
- **Параметры:**
  - `money` — сколько денег у покупателя
  - `price_per_item` — цена за один товар
  - `items_count` — количество товаров
- **Возвращает:** число со сдачей или строку "Недостаточно денег"
- **Пример вызова:**
  ```python
  change(100, 10, 5)   # вернет 50
  change(100, 10, 11)  # вернет 'Недостаточно денег'
  ```


## weekend_check(day)
Проверяет, выходной ли день.
- **Параметры:**
  - `day` — название дня недели строкой ("сб", "вс", "суббота", "воскресенье")
- **Возвращает:** True если выходной, иначе False
- **Пример вызова:**
  ```python
  weekend_check("Суббота")  # True
  weekend_check("пн")       # False
  ```



## even(num)
Проверяет четное ли число.
- **Параметры:**
  - `num` — целое число
- **Возвращает:** True если четное, иначе False
- **Пример вызова:**
  ```python
  even(4)  # True
  even(7)  # False
  ```



## multiples_of_three(start, end, step=1)
Возвращает список чисел из диапазона, которые делятся на 3. Значение end в диапазон не входит.
- **Параметры:**
  - `start` — начало диапазона
  - `end` — конец диапазона
  - `step` — шаг (по умолчанию 1)
- **Возвращает:** список чисел
- **Пример вызова:**
  ```python
  multiples_of_three(3, 12)  # [3, 6, 9]
  ```



## sentiment_score(text, positive_words, negative_words)
Считает настроение текста. Текст режется по пробелам, знаки препинания не убираются. Если в конце слова стоит знак !, счет умножается на 1.5, а если ? — на 0.3.
- **Параметры:**
  - `text` — строка с текстом
  - `positive_words` — список хороших слов
  - `negative_words` — список плохих слов
- **Возвращает:** число с итоговым счетом
- **Пример вызова:**
  ```python
  sentiment_score("I love cats!", ["love"], ["hate"])  # 1.5
  ```



## to_binary(num, bit_counter=0)
Переводит десятичное число в двоичное. Если счетчик битов не превышает 10, список не разворачивается и число возвращается задом наперед.
- **Параметры:**
  - `num` — число
  - `bit_counter` — начальное значение счетчика (по умолчанию 0)
- **Возвращает:** строку из 0 и 1
- **Пример вызова:**
  ```python
  to_binary(10)     # '0101'
  to_binary(10, 7)  # '1010'
  ```
