# Документация к mysterious_file.py

В файле `mysterious_file.py` находятся функции для работы со строками, числами и списками.

## make_tea

Функция формирует строку с описанием чая по заданному количеству воды и сахара.

Пример вызова:


make_tea(200, 2)

## buy_products
Функция рассчитывает стоимость покупки и возвращает сдачу.
Если денег недостаточно, функция возвращает сообщение "Недостаточно денег".
Пример вызова:
buy_products(100, 10, 5)


## is_weekend
Функция проверяет, является ли указанный день выходным.
Выходными считаются суббота и воскресенье.
Пример вызова:
is_weekend("Суббота")


## is_even
Функция проверяет, является ли переданное число чётным.
Пример вызова:
is_even(4)


## find_multiples_of_three
Функция находит числа, кратные трём, в указанном диапазоне.
Можно задать начало диапазона, конец диапазона и шаг перебора.
Пример вызова:
find_multiples_of_three(1, 10)


## sentiment_score
Функция определяет эмоциональную оценку текста.
Для анализа используются списки позитивных и негативных слов.
Пример вызова:
sentiment_score(    "I love Python!",    ["love", "like", "enjoy"],    ["hate", "dislike"])


## build_binary_string
Функция получает двоичные разряды числа и формирует из них строку.
Пример вызова:
build_binary_string(10)
