Документация функций
1. make_tea(water_ml, sugar_spoons)
Готовит описание чая с указанным количеством воды и сахара.
Аргументы:
•	water_ml (int) — объём воды в миллилитрах
•	sugar_spoons (int) — количество ложек сахара
Возвращает: str — описание напитка
Пример:
make_tea(200, 2)
# 'Чай: 200 мл воды, 2 ложки сахара'
2. buy_products(money, price_per_item, items_count)
Рассчитывает сдачу после покупки товаров.
Аргументы:
•	money (int) — сумма имеющихся денег
•	price_per_item (int) — цена одного товара
•	items_count (int) — количество товаров
Возвращает: int или str — сумму сдачи либо сообщение о нехватке денег
Пример:
buy_products(100, 10, 5)
# 50
3. check_weekend(day)
Проверяет, является ли день недели выходным.
Аргументы:
•	day (str) — название дня недели
Возвращает: bool — True, если день является субботой или воскресеньем, иначе False
Пример:
check_weekend("Суббота")
# True
4. check_even(number)
Проверяет, является ли число чётным.
Аргументы:
•	number (int) — целое число для проверки
Возвращает: bool — True, если число чётное, иначе False
Пример:
check_even(4)
# True
5. find_numbers(start, stop, step=1)
Находит числа, кратные трём, в заданном диапазоне.
Аргументы:
•	start (int) — начало диапазона
•	stop (int) — конец диапазона, не включается
•	step (int) — шаг изменения числа, по умолчанию 1
Возвращает: list — список чисел, кратных трём
Пример:
find_numbers(1, 10)
# [3, 6, 9]
6. calculate_sentiment(text, positive_words, negative_words)
Оценивает эмоциональную окраску текста по заданным словам.
Аргументы:
•	text (str) — текст для анализа.
•	positive_words (list) — список позитивных слов
•	negative_words (list) — список негативных слов
Возвращает: int или float — числовую оценку эмоциональной окраски текста
Пример:
calculate_sentiment("I love Python", ["love"], ["hate"])
# 1
7. convert_number(number, counter=0)
Преобразует число в строку из остатков от деления на два.
Аргументы:
•	number (int) — число для преобразования
•	counter (int) — начальное значение счётчика, по умолчанию 0
Возвращает: str — строку из остатков или "0", если число неположительное
Пример:
convert_number(10)
# '0101'
