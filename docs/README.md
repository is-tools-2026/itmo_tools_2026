# Документация проекта

Проект содержит набор утилит в файле [`mysterious_file.py`](../mysterious_file.py):
покупка товаров, проверка дня недели, работа с числами, оценка тональности текста
и перевод числа в двоичную запись.

## Описание функций

### `make_tea(water_ml, sugar_spoons)`

Готовит чай, смешивая воду и сахар. Возвращает текстовое описание напитка.

| Параметр | Тип | Описание |
| --- | --- | --- |
| `water_ml` | `int` | объём воды в миллилитрах |
| `sugar_spoons` | `int` | количество ложек сахара |

**Возвращает:** `str` — описание получившегося напитка.

```python
make_tea(200, 2)
# 'Чай: 200 мл воды, 2 ложки сахара'
```

### `buy_products(money, price_per_item, items_count)`

Покупает одинаковые товары и возвращает сдачу. Если денег не хватает,
возвращает сообщение об ошибке.

| Параметр | Тип | Описание |
| --- | --- | --- |
| `money` | `int \| float` | сумма денег у покупателя |
| `price_per_item` | `int \| float` | цена одного товара |
| `items_count` | `int` | количество покупаемых товаров |

**Возвращает:** `int | float | str` — сдача либо строка `"Недостаточно денег"`.

```python
buy_products(100, 10, 5)
# 50

buy_products(20, 10, 5)
# 'Недостаточно денег'
```

### `is_weekend(day)`

Проверяет, является ли день выходным (суббота или воскресенье).
Принимает короткие (`"сб"`, `"вс"`) и полные названия дня.

| Параметр | Тип | Описание |
| --- | --- | --- |
| `day` | `str` | название дня недели |

**Возвращает:** `bool` — `True`, если день выходной, иначе `False`.

```python
is_weekend("Суббота")
# True

is_weekend("понедельник")
# False
```

### `is_even(number)`

Проверяет, является ли число чётным.

| Параметр | Тип | Описание |
| --- | --- | --- |
| `number` | `int` | проверяемое целое число |

**Возвращает:** `bool` — `True`, если число делится на 2 без остатка.

```python
is_even(4)
# True

is_even(7)
# False
```

### `get_multiples_of_three(start, stop, step=1)`

Собирает числа из диапазона `[start, stop)`, которые делятся на 3.

| Параметр | Тип | Описание |
| --- | --- | --- |
| `start` | `int` | начало диапазона (включительно) |
| `stop` | `int` | конец диапазона (не включительно) |
| `step` | `int` | шаг перебора, по умолчанию `1` |

**Возвращает:** `list[int]` — список чисел, кратных трём.

```python
get_multiples_of_three(1, 10)
# [3, 6, 9]

get_multiples_of_three(0, 20, 2)
# [0, 6, 12, 18]
```

### `sentiment_score(text, positive_words, negative_words)`

Оценивает тональность текста по спискам позитивных и негативных слов.

- каждое позитивное слово даёт `+1`;
- каждое негативное слово даёт `-1`;
- восклицательный знак усиливает оценку в `1.5` раза;
- вопросительный знак ослабляет оценку в `0.3` раза.

| Параметр | Тип | Описание |
| --- | --- | --- |
| `text` | `str` | анализируемый текст |
| `positive_words` | `list[str]` | список позитивных слов |
| `negative_words` | `list[str]` | список негативных слов |

**Возвращает:** `float` — итоговая оценка, округлённая до 1 знака.

```python
sentiment_score(
    "I love Python!",
    ["love", "like", "enjoy", "adore", "appreciate"],
    ["hate", "dislike", "detest", "antipathy"],
)
# 1.5
```

### `decimal_to_binary(number, bit_count=0)`

Переводит неотрицательное целое число в двоичную запись.
Остатки от деления на 2 собираются от младшего бита к старшему.
Если количество битов больше 10, цифры разворачиваются
(старший бит оказывается слева). Для нуля возвращается `"0"`.

| Параметр | Тип | Описание |
| --- | --- | --- |
| `number` | `int` | неотрицательное целое число |
| `bit_count` | `int` | начальное значение счётчика битов, по умолчанию `0` |

**Возвращает:** `str` — двоичная запись числа.

```python
decimal_to_binary(10)
# '0101'

decimal_to_binary(0)
# '0'
```
