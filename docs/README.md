## Кассир

### `buy_products(money, price_per_item, items_count)`

- Покупает продукты, берет количество товаров и их цену, проверяет, хватит ли нам денег.

### Параметры

1. `money` (`int`): сумма денег
2. `price_per_item` (`int`): цена товара
3. `items_count` (`int`): количество товара

### Возвращает:

1. `str`:
   - `"Недостаточно денег"` — если у нас недостаточно средств
2. `int`:
   - возвращает сдачу, если денег достаточно

### Примеры:

```python
buy_products(200, 50, 5)  # "Недостаточно денег"
```

```python
buy_products(200, 25, 3)  # 125
```

## Функция 2

### `is_in_list(day)`

- Делает проверку на наличие элемента в заранее заготовленном списке, состоящем из дней недели.

### Параметры

1. `day` (`str`): элемент, наличие которого мы хотим проверить (день недели)
2. `arr` (`list`): массив дней недели

### Возвращает:

1. `bool`:
   - `True` — элемент есть в массиве
   - `False` — элемента в массиве нет

### Примеры:

```python
is_in_list("Суббота")  # True
```

```python
is_in_list("С")  # False
```

## Функция 4

### `troitsa(a, b, c)`

- Добавляет в список элементы, кратные трём.
- Создаёт список размерностью от `a` до `b` и добавляет в него элементы, кратные трём.

### Параметры

1. `a` (`int`): начало массива
2. `b` (`int`): конец массива
3. `c` (`int`): шаг массива

### Возвращает:

1. `list`:
   - генерирует список элементов, кратных трём

### Примеры:

```python
troitsa(1, 10, c=1)  # [3, 6, 9]
```

## Функция 5

### `sentiment_score(t, p_w, n_w)`

- Вычисляет оценку эмоциональной окраски текста.

### Параметры

1. `t` (`str`): текст, который мы передаём
2. `p_w` (`list`): список положительных слов
3. `n_w` (`list`): список отрицательных слов

### Возвращает:

1. `float`:
   - оценка эмоциональности текста, округлённая до одного знака после запятой

### Примеры:

```python
sentiment_score(
    "I love Python!",
    ["love", "like", "enjoy", "adore", "appreciate"],
    ["hate", "dislike", "detest", "antipathy"]
)  # 1.5
```

## Функция 6

### `f(x, y)`

- Переводит число в двоичную систему счисления.
- Если число равно нулю, возвращает `"0"`.

### Параметры

1. `x` (`int`): число, которое переводим в двоичную систему
2. `y` (`int`): счётчик

### Возвращает:

1. `str`:
   - двоичный результат числа
   - `"0"` — если число равно нулю

### Примеры:

```python
f(10, 0)  # "1010"
```

```python
f(0, 0)  # "0"
```
