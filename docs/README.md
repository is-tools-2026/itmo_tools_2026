Документация проекта Mysterious File

Описание проекта

Проект содержит набор учебных функций на Python. Исходный код находился в файле mysterious_file.py с непонятными именами функций и почти без документации. Мы привели код в порядок: дали функциям осмысленные имена, добавили docstring’и и создали структуру проекта.

Структура проекта

artifacts/
├── mysterious_file.py      # Основной модуль с функциями
└── docs/
    └── README.md           # Документация проекта (этот файл)

Описание функций с примерами вызова

1. make_tea(water_ml, sugar_spoons)

Краткое описание: формирует строку-описание чая по объёму воды и количеству сахара.

Args:

water_ml (int): объём воды в миллилитрах

sugar_spoons (int): количество ложек сахара

Returns:

str: описание напитка

Пример вызова:

>>> make_tea(200, 2)
'Чай: 200 мл воды, 2 ложки сахара'

2. calculate_change(money, price_per_item, items_count)

Краткое описание: вычисляет сдачу при покупке товаров. Если денег не хватает — возвращает сообщение об этом.

Args:

money (int | float): сумма денег у покупателя

price_per_item (int | float): цена одного товара

items_count (int): количество товаров

Returns:

int | float | str: сумма сдачи или строка «Недостаточно денег»

Пример вызова:

>>> calculate_change(100, 10, 5)
50

3. is_weekend(day)

Краткое описание: проверяет, является ли переданный день выходным (суббота или воскресенье).

Args:

day (str): название или сокращение дня недели

Returns:

bool: True, если день выходной, иначе False

Пример вызова:

>>> is_weekend("Суббота")
True

4. is_even(number)

Краткое описание: проверяет, является ли число чётным.

Args:

number (int): целое число для проверки

Returns:

bool: True, если число чётное, иначе False

Пример вызова:

>>> is_even(4)
True

5. get_multiples_of_three(start, stop, step=1)

Краткое описание: возвращает список чисел, кратных трём, в заданном диапазоне.

Args:

start (int): начало диапазона (включительно)

stop (int): конец диапазона (не включительно)

step (int): шаг итерации (по умолчанию 1)

Returns:

list[int]: список чисел, кратных 3

Пример вызова:

>>> get_multiples_of_three(1, 10)
[3, 6, 9]

6. sentiment_score(text, positive_words, negative_words)

Краткое описание: оценивает настроение текста по спискам позитивных и негативных слов. Учитывает восклицательные и вопросительные знаки.

Args:

text (str): анализируемый текст

positive_words (list[str]): список позитивных слов

negative_words (list[str]): список негативных слов

Returns:

float: итоговая оценка настроения (округлена до 1 знака)

Пример вызова:

>>> sentiment_score("I love Python!", ["love", "like"], ["hate", "dislike"])
1.5

7. to_binary(number, counter=0)

Краткое описание: преобразует целое число в его двоичное представление в виде строки.

Args:

number (int): целое число для преобразования

counter (int): вспомогательный счётчик итераций (по умолчанию 0)

Returns:

str: двоичное представление числа (или "0" для нуля)

Пример вызова:

>>> to_binary(10)
'1010'
