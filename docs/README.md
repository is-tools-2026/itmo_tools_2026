## Функция 1
### def bought_products(money, price_per_item, items_count):

- Вычитает сумму за покупку одинаковых товаров из общей суммы денег у пользователя 

### Параметры
1. `money` (int): Число денег у пользоавтеля
2. `price_per_item` (float): Цена одного товара
3. `items_count` (int): Число одинаковых товаров

**Возвращает:**  
1. `float`: Оставшиеся деньги у пользователя
2.  `str`: В противном случае "Недостаточно денег"

**Примеры:**
```python
# 1
bought_products(100, 10, 5) # 50

# --------
# 2 
bought_products(100, 100, 2) # "Недостаточно денег"

```
