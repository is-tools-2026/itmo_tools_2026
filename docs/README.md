# Документация проекта

Проект содержит набор функций на языке Python для выполнения различных задач: от расчёта сдачи до анализа настроения текста и работы с двоичной системой счисления.

---
## 1. Описание функций

### `make_tea`

Готовит чай, формируя текстовое описание напитка на основе объема воды и количества сахара.


* **Параметры:**

  * `water_ml` (`int`) - объём воды в миллилитрах.

  * `sugar_spoons` (`int`) - количество ложек сахара.

* **Возвращаемое значение:** `str` - описание получившегося напитка.


**Пример использования:**

```python

result = make_tea(200, 2)

print(result)  # выведет: 'Чай: 200 мл воды, 2 ложки сахара'

```

  

---
### `calculate_change`

Вычисляет сумму сдачи при покупке нескольких единиц товара.


* **Параметры:**

  * `money` (`int` | `float`) - имеющаяся сумма денег.

  * `price_per_item` (`int` | `float`) - стоимость одной единицы товара.

  * `items_count` (`int`) - количество покупаемых товаров.

* **Возвращаемое значение:** `int` | `float` | `str` - оставшаяся сдача или сообщение `"Недостаточно денег"`.


**Пример использования:**

```python

change = calculate_change(100, 10, 5)

print(change)  # выведет: 50

```

  

---
### `is_weekend`

Проверяет, является ли переданное название дня недели (или его сокращение) выходным днем (суббота или воскресенье).


* **Параметры:**

  * `day` (`str`) - название дня недели или его краткая форма.

* **Возвращаемое значение:** `bool` - `True`, если день выходной, иначе `False`.


**Пример использования:**

```python

print(is_weekend("Суббота"))  # выведет: True

print(is_weekend("пн"))       # выведет: False

```

  

---
### `is_even`

Проверяет целое число на чётность.


* **Параметры:**

  * `number` (`int`) - проверяемое целое число.

* **Возвращаемое значение:** `bool` - `True`, если число чётное, иначе `False`.
  

**Пример использования:**

```python

print(is_even(4))  # выведет: True

print(is_even(7))  # выведет: False

```

  

---
### `get_multiples_of_three`

Формирует список чисел, кратных 3, из указанного диапазона.

  
* **Параметры:**

  * `start` (`int`) - начало диапазона (включительно).

  * `stop` (`int`) - конец диапазона (не включительно).

  * `step` (`int`, опционально) - шаг итерации (по умолчанию 1).

* **Возвращаемое значение:** `list[int]` - список чисел, делящихся на 3 без остатка.


**Пример использования:**

```python

numbers = get_multiples_of_three(1, 10)

print(numbers)  # Выведет: [3, 6, 9]

```

  

---
### `analyze_sentiment`

Оценивает эмоциональную окраску текста на основе ключевых слов, с учётом эмоциональных знаков препинания (`!` и `?`).


* **Параметры:**

  * `text` (`str`) - входной текст.

  * `positive_words` (`list[str]`) - список позитивных слов :3

  * `negative_words` (`list[str]`) - список негативных слов :c

* **Возвращаемое значение:** `float` - итоговый балл настроения (округленный до одного знака после запятой).


**Пример использования:**

```python

score = analyze_sentiment(

    "I love Python!",

    ["love", "like", "enjoy"],

    ["hate", "dislike"]

)

print(score)  # выведет: 1.5

```

  

---
### `to_binary_string`

Переводит целое неотрицательное число в строку двоичного представления.


* **Параметры:**

  * `number` (`int`) - число для перевода.

  * `counter` (`int`, опционально) - начальное значение счётчика итераций (по умолчанию 0).

* **Возвращаемое значение:** `str` - двоичная строка.


**Пример использования:**

```python

binary = to_binary_string(10)

print(binary)  # выведет: '1010'

```
