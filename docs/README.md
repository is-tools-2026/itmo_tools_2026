# Документация проекта
## Функция make_tea
Функция делает описание чая с водой и сахаром
```python
def make_tea(water_ml,sugar_spoons):
```
Параметры
* `water_ml` (`int`) количество воды в миллилитрах
* `sugar_spoons` (`int`) количество ложек сахара
Возвращает строку с описанием чая
Пример
```python
make_tea(200,2)
```
Результат
```text
Чай: 200 мл воды, 2 ложки сахара
```
## Функция calculate_change
Функция считает сдачу после покупки
```python
def calculate_change(money,price_per_item,items_count):
```
Параметры
* `money` (`int,float`) количество денег
* `price_per_item` (`int,float`) цена одного товара
* `items_count` (`int`) количество товаров
Возвращает сдачу или сообщение если денег не хватает
Пример
```python
calculate_change(100,10,5)
```
Результат
```text
50
```
Если денег не хватает
```python
calculate_change(30,10,5)
```
Результат
```text
Недостаточно денег
```

## Функция is_weekend
Функция проверяет является ли день выходным
```python
def is_weekend(day):
```
Параметры
* `day` (`str`) название или сокращение дня недели
Возвращает `True` если это суббота или воскресенье
В остальных случаях возвращает `False`
Пример
```python
is_weekend("Суббота")
```
Результат
```text
True
```

## Функция convert_to_binary_with_counter

Для этого число несколько раз делится на 2

Счетчик показывает сколько раз выполнялось деление
```python
def convert_to_binary_with_counter(number,counter=0):
```
Параметры
* `number` (`int`) число для преобразования
* `counter` (`int`) начальное значение счетчика
