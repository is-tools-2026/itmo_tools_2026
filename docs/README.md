## Функция 0
### make_tea(water_ml, sugar_spoons)

- Функция "готовит чай", смешивая воду и сахар. 

### Параметры
1. `water_ml` (int): Объём воды в миллилитрах
2. `sugar_spoons` (int): Количество ложек сахара

**Возвращает:**  
1. `str`: Описание получившегося напитка

**Примеры:**
```python
# 1
make_tea(200, 2) # Чай: 200 мл воды, 2 ложки сахара

```

``` python
# 2 
make_tea(3200, 4) # Чай: 3200 мл воды, 4 ложки сахара

```

## Функция 1
### def bought_products(money, price_per_item, items_count):

- Функция Вычитает сумму за покупку одинаковых товаров из общей суммы денег у пользователя 

### Параметры
1. `money` (int): Число денег у пользовавтеля
2. `price_per_item` (float): Цена одного товара
3. `items_count` (int): Число одинаковых товаров

**Возвращает:**  
1. `int` или `float`: Оставшиеся деньги у пользователя
2. `str`: В противном случае "Недостаточно денег", если денег не хватает

**Примеры:**
```python
# 1
bought_products(100, 10, 5) # 50

```

``` python
# 2 
bought_products(100, 100, 2) # "Недостаточно денег"

```

## Функция 4
### multiples_of_3(prm1, prm2, step = 1):

- Функция возвращает список чисел, кратных 3

### Параметры
1. `prm1` (int): Начало диапозона перебора индексов
2. `prm2` (int): Конец диапозона перебора индексов
3. `step` (int) - Шаг перебора индексов
    - Если при вызове ф-ции шаг(step) **не обозначаем** => `step = 1`
    - Если при вызове ф-ции шаг(step) **обозначаем** => `step` = <введённое число>

**Возвращает:**
1. `list`: Список чисел, которые делятся на 3


**Примеры:**
```python
# 1
multiples_of_3(0, 13) # [0, 3, 6, 9]

```
```python
# 2 
multiples_of_3(0, 13, 2) # [0, 6, 12]

```

```python
# 3
multiples_of_3(0, 4, 1) # [0, 3]

```

## Функция 5
### sentiment_score(txt, pos, neg):

- Функция возвращает коэффицент (оценку) того, на сколько сильно текст был эмоционально окрашен

### Параметры
1. `txt` (str): Строка, которую будет оценивать функция
2. `pos` (list): Список положительных слов (прилагательных)
3. `neg` (list) - Список негативных слов (прилагательных)

**Возвращает:**
1. `float`: Коэффицент эмоциональной окраски текста, округлённый до десятых 


**Примеры:**
```python
# 1
sentiment_score("I love Python!", ["love", "like", "enjoy", "adore", "appreciate"], ["hate", "dislike", "detest", "antipathy"]) # 1.5

```
```python
# 2 
sentiment_score("love like enjoy", ["love", "like", "enjoy"], ["hate"]) # 3.0

```

```python
# 3
sentiment_score("Do I love! Python", ["love"], ["hate"]) # 0.0

```

## Функция 6
### transform_into_binary(num, count = 0):

- Функция делает перевод числа из десятичной системы счистления в двоичную и выводит результат. В текущей версии переменная count не выводится 


### Параметры
1. `num` (int): Число в десятичной системы счистления
2. `count` (int): Количество итераций
    

**Возвращает:**
1. `str`: Строка из символов входящего числа в двоичной системе счистления



**Примеры:**
```python
# 1
transform_into_binary(10) # '0101'

```
```python
# 2 
transform_into_binary(10, 3) # ('0101', 7)

```

```python
# 3
transform_into_binary(12) # ('1100', 4)

```

```python
# 4
transform_into_binary(12, 23) # ('1100', 27)

```
