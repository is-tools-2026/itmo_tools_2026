# Документация к mysterious_file.py

## функция 1
### buy_products(money, price_per_item, items_count)

Считает итоговую сумму за покупку товаров и остаток после покупки

| Параметр        | Тип  | Описание                  |
|-----------------|------|---------------------------|
| money           | int  | количество имеющихся денег|
| price_per_item  | int  | цена одного товара        |
| items_count     | int  | количество товаров        |

**Возвращает:** `str` — `"Недостаточно денег"` если денег не хватает или `int` — остаток денег после покупки

**Пример:**
```python
buy_products(100, 10, 5)   # 50

```

## функция 2
### check(day)

Проверяет находится ли переданное в прогармму слово(аббривеатура слова) в списке

| Параметр | Тип  | Описание                         |
|----------|------|----------------------------------|
| day      | str  | слово или аббривеатура дня недели|

**Возвращает:** `bool` —  значение,которое отвечает на вопрос:принадлежит ли слово списку?

**Пример:**
```python
check("понедельник")   # False
check("воскресенье")   # True
```

## функция 3
### check_even(num)

Проверяет, является ли число чётным

| Параметр | Тип | Описание                  |
|----------|-----|---------------------------|
| num      | int | число для проверки        |

**Возвращает:** `bool` — `True` если число чётное иначе `False`

**Пример:**
```python
check_even(4)   # True
check_even(7)   # False
```
## функция 4
### div3_in_range(start, end, step=1)

Возвращает числа, которые делятся на 3 без остатка в заданном диапазоне

| Параметр | Тип | Описание                              |
|----------|-----|---------------------------------------|
| start    | int | начало диапазона                      |
| end      | int | конец диапазона, не включается        |
| step     | int | шаг диапазона,установлен по умолчанию |

**Возвращает:** `list` — список чисел кратных 3

**Пример:**
```python
div3_in_range(2, 15)   # [3, 6, 9, 12]
```
## функция 5
### emotional_scale(text, positive, negative)

Вычисляет эмоциональную оценку текста на основе положительных и отрицательных слов

| Параметр | Тип  | Описание                              |
|----------|------|---------------------------------------|
| text     | str  | текст для анализа                     |
| positive | list | список положительных слов             |
| negative | list | список отрицательных слов             |

**Возвращает:** `float` — эмоциональную оценку текста, округлённую до десятых

**Пример:**
```python
emotional_scale(
    "I love Python!",
    ["love", "like", "enjoy", "adore", "appreciate"],
    ["hate", "dislike", "detest", "antipathy"]) # 1.5
```

## функция 6
### translation_into_binary(num, count=0)

Переводит число из десятичной системы счисления в двоичную

| Параметр | Тип | Описание                              |
|----------|-----|---------------------------------------|
| num      | int | число для перевода                    |
| count    | int | счётчик итераций, установлен по умолчанию|

**Возвращает:** `str` — число в двоичной системе счисления

**Пример:**
```python
translation_into_binary(10)   # 0101
```
