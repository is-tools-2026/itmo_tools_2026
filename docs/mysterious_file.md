### **Документирование по файлу mysterious_file.py**

#### Описание функций с примерами

Код в файле mysterious_file.py содержит в себе 6 функций.
1. **def buy_products(money, price_per_item, items_count)** - вычисление сдачи при оплате товара. При нехватке денежных средств выводит "Недостаточно денег".
##### Аргументы функции:
    - money: Сумма денежных средств у покупателя.
    - price_per_item: Цена за единицу товара.
    - items_count: Количество оплачиваемых товаров.
*Пример:* 
    `buy_products(100, 15, 4)`
        Выведет `40`
    `buy_products(20, 15, 2)`
        Выведет `Недостаточно денег`

2. **def weekends(day)** - проверка, является ли введенный день недели выходным.
##### Аргументы функции:
    - day: Название дня недели или его сокращение.
*Пример:* 
    `weekends("Суббота")`
        Выведет `True`
    `weekends("Вторник")`
        Выведет `False`

3. **division(number)** - проверка числа на четность (делится ли на 2 без остатка).
###### Аргументы функции:
    - number: Проверяемое число.
*Пример:*
    `division(1006)`
        Выведет `True`
    `division(739)`
        Выведет `False`

4. **division_by_tree(start, finish, step=1)** - проверяем, кратно ли число 3 (делится без остатка) в заданном диапазоне.
##### Аргументы функции:
    - start: Первое число из диапазона.
    - finish: Последнее число из диапазона.
    - step: Шаг генерации чисел (по умолчанию равен 1).
*Пример:*
    `division_by_tree(1, 10)`
        Выведет `[3, 6, 9]`

5. **sentiment_analyze(text, positive_words, negative_words)** - определение эмоциональной окраски текста на основе ключевых слов.
##### Аргументы функции:
    - text: Исходный текст для анализа.
    - positive_words: Список слов с позитивной окраской.
    - negative_words: Список слов с негативной окраской.
*Пример:*
    `sentiment_analyze("Отличный ужин", ["отличный"], [])`
        Выведет `1.5`

6. **binary(number, bit_count=0)** - Перевод числа в двоичную систему счисления, учитывая ограничения по ТЗ.
##### Аргументы функции:
    - number: Десятичное число для перевода.
    - bit_count: Начальное значение счетчика бит (по умолчанию 0).
*Пример:*
    `binary(12)`
        Вернет `01100`
