# Документация функций

| Функция | Описание | Параметры | Возвращаемое значение | Пример |
|---|---|---|---|---|
| `make_tea` | Готовит чай, смешивая указанное количество воды и сахара. | `water_ml` (`int`) — объём воды в миллилитрах; `sugar_spoons` (`int`) — количество ложек сахара. | `str` — описание получившегося напитка. | `make_tea(200, 2)` → `'Чай: 200 мл воды, 2 ложки сахара'` |
| `buy_products` | Рассчитывает общую стоимость покупки и сдачу. Если денег недостаточно, возвращает сообщение об этом. | `money` (`int \| float`) — количество денег; `price_per_item` (`int \| float`) — цена одного товара; `items_count` (`int`) — количество товаров. | `int \| float \| str` — сдача или `"Недостаточно денег"`. | `buy_products(100, 10, 5)` → `50` |
| `is_weekend_day` | Проверяет, является ли указанный день субботой или воскресеньем. | `day` (`str`) — название или сокращённое название дня недели. | `bool` — `True`, если день выходной, иначе `False`. | `is_weekend_day("Суббота")` → `True` |
| `is_even` | Проверяет, является ли число чётным. | `number` (`int`) — целое число для проверки. | `bool` — `True`, если число чётное, иначе `False`. | `is_even(4)` → `True` |
| `get_multiples_of_three` | Находит числа, кратные трём, в заданном диапазоне с указанным шагом. | `start` (`int`) — начало диапазона; `stop` (`int`) — конец диапазона; `step` (`int`) — шаг. | `list[int]` — список чисел, которые делятся на 3 без остатка. | `get_multiples_of_three(1, 10)` → `[3, 6, 9]` |
| `calculate_sentiment_score` | Рассчитывает оценку эмоциональной окраски текста. Положительные слова увеличивают оценку, отрицательные уменьшают. `!` умножает оценку на 1.5, `?` — на 0.3. | `text` (`str`) — текст; `positive_words` (`list[str]`) — положительные слова; `negative_words` (`list[str]`) — отрицательные слова. | `float` — итоговая оценка, округлённая до одного знака. | `calculate_sentiment_score("I love Python!", ["love"], ["hate"])` → `1.5` |
| `convert_to_binary` | Последовательно получает остатки от деления числа на 2 и формирует из них строку. Если счётчик итераций больше 10, последовательность разворачивается. | `number` (`int`) — исходное число; `iteration_count` (`int`) — начальное значение счётчика. | `str` — строка из полученных остатков. Для `0` возвращается `"0"`. | `convert_to_binary(10)` → `'0101'` |
