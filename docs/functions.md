# Functions

## Функция 1 — `buy_products`

**Описание:** Считает сдачу. Если общая стоимость товаров превышает доступную сумму денег, возвращает `"Недостаточно денег"`

**Параметры:**
- `money` (`int`): количество денег покупателя.
- `price_per_item` (`int`): цена одного товара.
- `items_count` (`int`): количество покупаемых товаров.

**Возвращаемое значение:**
- `int` — сдача.
- `str` — `"Недостаточно денег"`, если средств не хватает.

**Пример вызова:**

```python
buy_products(100, 10, 5)
```

**Результат:**
```text
50
```

Пример, когда денег недостаточно:

```python
buy_products(10, 10, 5)
```

**Результат:**
```text
Недостаточно денег
```


## Функция 4 — `find_numbers_multiple_of_three`

**Описание:** находит все числа, кратные трём, в заданном диапазоне,числа перебираются с указанным шагом.

**Параметры:**
- `firstnumber` (`int`) — начало диапазона.
- `lastnumber` (`int`) — конечная граница диапазона, не включается.
- `step` (`int`) — шаг перебора чисел, по умолчанию `1`

**Возвращаемое значение:**
- `list[int]` — список целых чисел, кратных трём.

**Пример вызова:**

```python
find_numbers_multiple_of_three(1, 7, 1)
```

**Результат:**
```text
[3, 6]
```

Пример с шагом 2:

```python
find_numbers_multiple_of_three(1, 11, 2)
```

**Результат:**
```text
[3, 9]
```

## Функция 5 — `sentiment_score`

**Описание:** вычисляет оценку эмоциональной окраски текста на основе списков позитивных и негативных слов.

Для каждого слова:
- если оно содержится в списке позитивных слов, оценка увеличивается на 1;
- если оно содержится в списке негативных слов, оценка уменьшается на 1;
- если слово заканчивается на `!`, текущая оценка умножается на 1.5;
- если слово заканчивается на `?`, текущая оценка умножается на 0.3.

В конце результат округляется до одного знака после запятой.

**Параметры:**
- `text` (`str`) — анализируемый текст.
- `positive_words` (`list[str]`) — список позитивных слов.
- `negative_words` (`list[str]`) — список негативных слов.

**Возвращаемое значение:**
- `float` — итоговая оценка эмоциональной окраски.

**Пример вызова:**

```python
sentiment_score(
    "I love Python!",
    ["love", "like", "enjoy", "adore", "appreciate"],
    ["hate", "dislike", "detest", "antipathy"]
)
```

**Результат:**
```text
1.5
```

## Функция 6 — `binary_digit`

**Описание:** Функция вычисляет позитивность текста(text) по правилам: если в тексте есть слова из списка позитивных слов positive_words, к счету(score) прибавляется балл, если есть слово из негативных слов negative_words, балл отнимается. Если в тексте есть вопросительный или восклицательный знак, счет умножается соответственно либо на 0.3, либо на 1.5. Счет округлен до 1 знака после запятой.

**Параметры:**
- `number` (`int`) — исходное неотрицательное целое число.
- `steps` (`int`) — начальное значение счётчика итераций, по умолчанию `0`

**Возвращаемое значение:**
- `str` — строка из цифр `0` и `1`. Если число равно нулю, возвращается строка `"0"`.

**Пример вызова:**

```python
binary_digit(10)
```

**Результат:**
```text
0101
```
