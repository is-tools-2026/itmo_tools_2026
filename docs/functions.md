## make_tea

Формирует строку с описанием чая из заданного объёма воды и количества ложек сахара.

**Параметры:**

| Параметр | Тип | Описание |
|---|---|---|
| `water_ml` | `int` | объём воды в миллилитрах |
| `sugar_spoons` | `int` | количество ложек сахара |

**Возвращает:** `str` — описание напитка.

**Особенности:** слово «ложки» в строке записано неизменно, поэтому при 5 ложках получится «5 ложки» (склонение не учитывается).

**Пример вызова:**

```python
make_tea(200, 2)   # 'Чай: 200 мл воды, 2 ложки сахара'
```

## calculate_change

Вычисляет сдачу при покупке нескольких одинаковых товаров.

**Параметры:**

| Параметр | Тип | Описание |
|---|---|---|
| `money` | `int \| float` | сумма денег у покупателя |
| `price_per_item` | `int \| float` | цена одного товара |
| `items_count` | `int` | количество товаров |

**Возвращает:** `int | float | str` — сдачу (`money - price_per_item * items_count`) либо строку `"Недостаточно денег"`, если стоимость покупки больше суммы денег.

**Особенности:**
- при нехватке денег функция **не выбрасывает исключение**, а возвращает строку, поэтому результат нужно проверять по типу;
- если денег ровно столько, сколько стоит покупка, вернётся `0`;
- налоги и скидки не учитываются.

**Примеры вызова:**

```python
calculate_change(100, 10, 5)    # 50
calculate_change(100, 10, 10)   # 0
calculate_change(100, 10, 11)   # 'Недостаточно денег'
```

## is_weekend

Проверяет, является ли день недели выходным (суббота или воскресенье).

**Параметры:**

| Параметр | Тип | Описание |
|---|---|---|
| `day` | `str` | название или сокращение дня недели |

**Возвращает:** `bool` — `True` для выходного дня, иначе `False`.

**Особенности:**
- регистр не важен (`"Суббота"`, `"суббота"`, `"СБ"` дают `True`);
- распознаются только русские значения: `сб`, `вс`, `суббота`, `воскресенье`;
- любая другая строка (включая английские `"Saturday"` и опечатки) даёт `False`;
- пробелы по краям не обрезаются: `" сб"` даст `False`.

**Примеры вызова:**

```python
is_weekend("Суббота")   # True
is_weekend("вс")        # True
is_weekend("Пятница")   # False
is_weekend("Saturday")  # False
```

## is_even

Проверяет, является ли целое число чётным.

**Параметры:**

| Параметр | Тип | Описание |
|---|---|---|
| `number` | `int` | целое число для проверки |

**Возвращает:** `bool` — `True`, если число чётное, иначе `False`.

**Особенности:** работает и для отрицательных чисел и для нуля (`0` чётное).

**Примеры вызова:**

```python
is_even(4)    # True
is_even(7)    # False
is_even(0)    # True
is_even(-3)   # False
```

## get_multiples_of_three

Возвращает список чисел, кратных трём, из диапазона `range(start, stop, step)`.

**Параметры:**

| Параметр | Тип | Описание |
|---|---|---|
| `start` | `int` | начало диапазона (включительно) |
| `stop` | `int` | конец диапазона (не включительно) |
| `step` | `int` | шаг перебора, по умолчанию `1` |

**Возвращает:** `list[int]` — числа, кратные 3, в порядке перебора.

**Особенности:**
- число `0` тоже кратно трём, поэтому при `start <= 0` оно попадёт в результат;
- при `step`, отличном от 1, проверяются только числа, которые попали в диапазон с этим шагом, поэтому результат может быть неожиданным. Например, при `start=1, step=3` перебираются 1, 4, 7, и результат пустой;
- при `step=0` будет ошибка `ValueError` (так ведёт себя `range`).

**Примеры вызова:**

```python
get_multiples_of_three(1, 10)       # [3, 6, 9]
get_multiples_of_three(0, 10)       # [0, 3, 6, 9]
get_multiples_of_three(1, 10, 2)    # [3, 9]
get_multiples_of_three(1, 10, 3)    # []
```

## sentiment_score

Вычисляет оценку настроения текста по спискам позитивных и негативных слов.

**Параметры:**

| Параметр | Тип | Описание |
|---|---|---|
| `text` | `str` | анализируемый текст |
| `positive_words` | `list[str]` | позитивные слова (в нижнем регистре) |
| `negative_words` | `list[str]` | негативные слова (в нижнем регистре) |

**Возвращает:** `int | float` — оценка настроения, округлённая до одного знака после запятой. Если в тексте нет ни одного знака `!` или `?` на конце слов, вернётся целое число.

**Алгоритм:**
1. Текст приводится к нижнему регистру и делится по пробелам.
2. Слова обрабатываются по порядку: позитивное слово даёт `+1`, негативное `-1`.
3. Если слово заканчивается на `!`, **весь накопленный счёт** умножается на `1.5`; если на `?`, то на `0.3`.

**Особенности (подвохи):**
- множитель применяется ко всей накопленной сумме, а не к одному слову, поэтому **порядок слов влияет на результат**;
- слово с пунктуацией на конце (`"love!"`, `"love,"`) не совпадает со списками, баллов не даёт, но `!` и `?` на его конце всё равно меняют счёт;
- для отрицательного счёта `!` усиливает негатив (`-1 → -1.5`);
- если на момент `!` или `?` счёт равен 0, он остаётся 0.

**Примеры вызова:**

```python
pos = ["love", "like"]
neg = ["hate", "dislike"]

sentiment_score("I love Python!", pos, neg)    # 1.5  (love: +1, затем "python!" умножает на 1.5)
sentiment_score("I hate this", pos, neg)       # -1
sentiment_score("I hate Python!", pos, neg)    # -1.5
sentiment_score("I love it?", pos, neg)        # 0.3
sentiment_score("Python! I love", pos, neg)    # 1    (множитель сработал до того, как появился балл)
sentiment_score("love!", pos, neg)             # 0.0  ("love!" не совпало со списком)
```

## to_binary

Преобразует неотрицательное целое число в строку с его двоичным представлением.

**Параметры:**

| Параметр | Тип | Описание |
|---|---|---|
| `number` | `int` | неотрицательное целое число |

**Возвращает:** `str` — двоичная запись числа без префикса `0b`; для нуля возвращается `"0"`.

**Исключения:** `ValueError` — если число отрицательное.

**Алгоритм:** число делится на 2 с остатком до нуля, остатки собираются в список, затем список разворачивается и склеивается в строку.

**Примеры вызова:**

```python
to_binary(10)     # '1010'
to_binary(0)      # '0'
to_binary(2048)   # '100000000000'
to_binary(-5)     # ValueError: Число должно быть неотрицательным
```
