# Документация функций

## 1. make_tea

Готовит чай, смешивая воду и сахар.

### Параметры

- `water_ml` (`int`) — объём воды в миллилитрах.
- `sugar_spoons` (`int`) — количество ложек сахара.

### Возвращает

`str` — описание получившегося напитка.

### Пример использования

```python
make_tea(200, 2)
```

Результат:

```text
Чай: 200 мл воды, 2 ложки сахара
```

## 2. calculate_change

Рассчитывает сдачу после покупки товаров.

Если денег недостаточно для покупок, функция возвращает сообщение "Недостаточно денег."


### Параметры

- `money` (`int | float`) — количество денег у покупателя.
- `price_per_item` (`int | float`) — цена одного товара.
- `items_count` (`int`) — количество товаров.

### Возвращает

`int | float | str` — сдача или сообщение о недостатке денег.

### Пример использования

```python
calculate_change(100, 10, 5)
```

Результат:

```text
50
```

## 3. is_weekend

Проверяет, является ли день выходным.

Функция проверяет субботу и воскресенье, а также сокращённые варианты "сб" и "вс".


### Параметры

- `day` (`str`) — название дня недели.

### Возвращает

`bool` — `True`, если день является субботой или воскресеньем, иначе `False`.

### Пример использования

```python
is_weekend("Суббота")
```

Результат:

```text
True
```

## 4. is_even

Проверяет, является ли число чётным.

### Параметры

- `number` (`int`) — целое число для проверки.

### Возвращает

`bool` — `True`, если число чётное, иначе `False`.

### Пример использования

```python
is_even(10)
```

Результат:

```text
True
```

## 5. get_multiples_of_three

Возвращает список чисел, кратных трём, в заданном диапазоне.

Функция перебирает числа от 'start' до 'end' с указанным шагом 'step' и добавляет в результат только те числа, которые делятся на 3 без остатка.


### Параметры

- `start` (`int`) — начало диапазона.
- `end` (`int`) — конец диапазона, который не включается.
- `step` (`int`) — шаг перебора чисел.

### Возвращает

`list[int]` — список чисел, кратных трём.

### Пример использования

```python
get_multiples_of_three(1, 10)
```

Результат:

```text
[3, 6, 9]
```

## 6. sentiment_score

Определяет настроение текста на основе положительных и отрицательных слов.

За положительное слово добавляется 1, за отрицательное слово вычитается 1.

Если слово заканчивается на `!`, текущая оценка умножается на 1.5.

Если слово заканчивается на `?`, текущая оценка умножается на 0.3.

### Параметры

- `text` (`str`) — текст для анализа.
- `positive_words` (`list[str]`) — список положительных слов.
- `negative_words` (`list[str]`) — список отрицательных слов.

### Возвращает

`float` — оценкуа настроения текста.


### Пример использования

```python
sentiment_score(
    "I love Python!",
    ["love", "like"],
    ["hate", "dislike"]
)
```

Результат:

```text
1.5
```

## 7. to_binary

Переводит числа в двоичную систему счисления.

Функция последовательно делит число на 2 и сохраняет остатки от деления.

### Параметры

- `number` (`int`) — целое число для перевода.
- `counter` (`int`) — счётчик итераций.

### Возвращает

`str` — двоичное представление числа в виде строки.

### Пример использования

```python
to_binary(10)
```

Результат:

```text
0101
```
