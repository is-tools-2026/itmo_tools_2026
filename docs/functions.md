# Документация функций

Данный документ содержит описание функций из файла `mysterious_file.py`, их параметров, возвращаемых значений и примеров использования.

## `buy_products`

Проверяет, хватает ли средств для покупки заданного количества товаров, и рассчитывает остаток баланса.

### Параметры

| Параметр | Тип | Описание |
|---|---|---|
| `balance` | `float` | Текущий баланс покупателя |
| `price_per_item` | `float` | Цена одного товара |
| `items_count` | `int` | Количество товаров |

### Возвращаемое значение

Возвращает остаток баланса после покупки. Если средств недостаточно, возвращает сообщение `Недостаточно денег`.

### Пример

```python
buy_products(100, 10, 5)
```

Результат:

```text
50
```

## `is_weekend`

Проверяет, является ли указанный день недели выходным днём.

### Параметры

| Параметр | Тип | Описание |
|---|---|---|
| `day` | `str` | Название или сокращённое обозначение дня недели |

### Возвращаемое значение

Возвращает `True`, если указанная строка обозначает субботу или воскресенье, иначе возвращает `False`.

### Пример

```python
is_weekend("Суббота")
```

Результат:

```text
True
```

## `is_even`

Проверяет, является ли число чётным.

### Параметры

| Параметр | Тип | Описание |
|---|---|---|
| `number` | `int` | Число для проверки |

### Возвращаемое значение

Возвращает `True`, если число является чётным, иначе `False`.

### Пример

```python
is_even(10)
```

Результат:

```text
True
```

## `find_multiples_of_three`

Находит числа, кратные трём, в заданном диапазоне с указанным шагом.

### Параметры

| Параметр | Тип | Описание |
|---|---|---|
| `start` | `int` | Начало диапазона |
| `stop` | `int` | Конец диапазона, не включая его |
| `step` | `int` | Шаг перебора чисел |

### Возвращаемое значение

Возвращает список чисел из заданного диапазона, которые делятся на три без остатка.

### Пример

```python
find_multiples_of_three(1, 11)
```

Результат:

```text
[3, 6, 9]
```

## `calculate_sentiment_score`

Вычисляет оценку тональности текста на основе списков позитивных и негативных слов.

### Параметры

| Параметр | Тип | Описание |
|---|---|---|
| `text` | `str` | Текст для анализа |
| `positive_words` | `list` | Список позитивных слов |
| `negative_words` | `list` | Список негативных слов |

### Возвращаемое значение

Возвращает числовую оценку тональности текста типа `float`.

### Пример

```python
calculate_sentiment_score(
    "I love Python!",
    ["love", "like", "enjoy", "adore", "appreciate"],
    ["hate", "dislike", "detest", "antipathy"]
)
```

Результат:

```text
1.5
```

## `convert_to_binary`

Переводит целое число в строковое представление в двоичной системе счисления.

### Параметры

| Параметр | Тип | Описание |
|---|---|---|
| `number` | `int` | Число, которое необходимо перевести |
| `counter` | `int` | Счётчик итераций алгоритма |

### Возвращаемое значение

Возвращает строку с двоичным представлением числа.

### Пример

```python
convert_to_binary(10)
```

Результат:

```text
0101
```
