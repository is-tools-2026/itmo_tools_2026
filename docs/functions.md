# Документация проекта
---

## Описание проекта

Проект представляет собой набор функций на языке Python для выполнения
простых вычислений, проверки условий, обработки текста и преобразования чисел.

**Основная цель проекта** — продемонстрировать работу с функциями,
условными операторами, циклами, строками, списками и арифметическими операциями.

---

## Требования

- **Язык программирования:** Python 3
- **Дополнительные библиотеки:** не требуются
- **Тип проекта:** набор вспомогательных функций

## Описание функций

### Функция `make_tea()`

**Назначение:** формирует текстовое описание напитка на основе объёма воды и количества ложек сахара.

**Сигнатура:** `make_tea(water_ml, sugar_spoons)`

**Параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `water_ml` | int | Объём воды в миллилитрах |
| `sugar_spoons` | int | Количество ложек сахара |

**Возвращаемое значение:**
- `str` — описание напитка.

**Пример использования:**
```python
print(make_tea(200, 2))
```
**Результат:**
```
Чай: 200 мл воды, 2 ложки сахара
```

**Особенности:** функция формирует строку с использованием f-string. Проверка корректности входных данных не выполняется.

### Функция `buy_products()`

**Назначение:** рассчитывает общую стоимость покупки и определяет размер сдачи.

**Сигнатура:** `buy_products(money, price_per_item, items_count)`

**Параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `money` | int \| float | Доступная сумма денег |
| `price_per_item` | int \| float | Стоимость одной единицы товара |
| `items_count` | int | Количество приобретаемых товаров |

**Возвращаемое значение:**
- `int | float` — размер сдачи, если денег достаточно;
- `str` — сообщение `"Недостаточно денег"`, если стоимость покупки превышает доступную сумму.

**Пример использования:**
```python
print(buy_products(100, 10, 5))
print(buy_products(30, 10, 6))
```
**Результат:**
```
50
Недостаточно денег
```

**Алгоритм работы:**
1. Вычисляется общая стоимость товаров.
2. Стоимость сравнивается с доступной суммой.
3. Если денег недостаточно — возвращается сообщение об ошибке.
4. В противном случае возвращается сдача.

**Формула расчёта:**
```
total = price_per_item * items_count
change = money - total
```

### Функция `is_weekend()`

**Назначение:** проверяет, является ли переданный день недели выходным.

**Сигнатура:** `is_weekend(day)`

**Параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `day` | str | Название или сокращённое обозначение дня недели |

**Возвращаемое значение:**
- `bool` — `True`, если день распознан как суббота или воскресенье; иначе `False`.

**Пример использования:**
```python
print(is_weekend("Суббота"))
print(is_weekend("Среда"))
print(is_weekend("ВС"))
```
**Результат:**
```
True
False
True
```

**Особенности:** перед проверкой строка переводится в нижний регистр. Функция распознаёт следующие обозначения: `сб`, `вс`, `суббота`, `воскресенье`. Другие варианты (`суб.`, `воскр.`) не поддерживаются.

### Функция `is_even()`

**Назначение:** определяет, является ли целое число чётным.

**Сигнатура:** `is_even(number)`

**Параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `number` | int | Число для проверки |

**Возвращаемое значение:**
- `bool` — `True`, если число чётное; иначе `False`.

**Пример использования:**
```python
print(is_even(4))
print(is_even(7))
print(is_even(-2))
```
**Результат:**
```
True
False
True
```

**Алгоритм работы:** используется оператор остатка от деления `%`. Если остаток от деления числа на два равен нулю — число чётное.

```python
return number % 2 == 0
```

### Функция `find_multiples_of_three()`

**Назначение:** формирует список чисел, кратных трём, из заданного диапазона.

**Сигнатура:** `find_multiples_of_three(start, stop, step=1)`

**Параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `start` | int | Начало диапазона, включительно |
| `stop` | int | Конец диапазона, не включительно |
| `step` | int (optional) | Шаг изменения числа. По умолчанию 1 |

**Возвращаемое значение:**
- `list[int]` — список чисел, делящихся на три без остатка.

**Пример использования:**
```python
print(find_multiples_of_three(0, 10))
print(find_multiples_of_three(0, 20, 2))
```
**Результат:**
```
[0, 3, 6, 9]
[0, 6, 12, 18]
```

**Алгоритм работы:**
1. Создаётся пустой список результатов.
2. Перебираются числа в диапазоне с указанным шагом.
3. Каждое число проверяется на делимость на три.
4. Числа, удовлетворяющие условию, добавляются в список.
5. Возвращается итоговый список.

**Особенности:** при `step=0` Python вызывает `ValueError`.

### Функция `calculate_sentiment_score()`

**Назначение:** оценивает эмоциональную окраску текста на основе наличия позитивных и негативных слов.

**Сигнатура:** `calculate_sentiment_score(text, positive_words, negative_words)`

**Параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `text` | str | Анализируемый текст |
| `positive_words` | list[str] | Список позитивных слов |
| `negative_words` | list[str] | Список негативных слов |

**Возвращаемое значение:**
- `float` — оценка настроения, округлённая до одного знака после запятой.

**Правила оценки:**
- За каждое позитивное слово начисляется `+1`.
- За каждое негативное слово начисляется `-1`.
- Если обрабатываемое слово заканчивается на `!`, текущая оценка умножается на `1.5`.
- Если обрабатываемое слово заканчивается на `?`, текущая оценка умножается на `0.3`.

**Пример использования:**
```python
print(
    calculate_sentiment_score(
        "I love Python!",
        ["love", "like", "enjoy", "adore", "appreciate"],
        ["hate", "dislike", "detest", "antipathy"]
    )
)
```
**Результат:** `1.5`

**Второй пример:**
```python
print(
    calculate_sentiment_score(
        "I hate bugs?",
        ["love"],
        ["hate"]
    )
)
```
**Результат:** `-0.3`

**Алгоритм работы:**
1. Текст переводится в нижний регистр.
2. Строка разбивается на слова с помощью `split()`.
3. Каждое слово проверяется на принадлежность к спискам позитивных и негативных слов.
4. При наличии знака `!` или `?` применяется соответствующий множитель.
5. Итоговое значение округляется до одного знака после запятой.

**Ограничения:**
- Знаки препинания не удаляются перед сравнением слов со списками.
- Регистр слов в исходных списках должен соответствовать нижнему регистру.
- Множитель применяется к текущей общей оценке на каждой итерации, а не только к баллу конкретного слова.
- Функция представляет собой упрощённый анализ текста и не учитывает контекст, отрицания и сложные языковые конструкции.

### Функция `to_binary_string()`

**Назначение:** преобразует неотрицательное целое число в строку, состоящую из двоичных цифр.

**Сигнатура:** `to_binary_string(number, iterations=0)`

**Параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `number` | int | Число для преобразования |
| `iterations` | int (optional) | Начальное значение счётчика итераций. По умолчанию 0 |

**Возвращаемое значение:**
- `str` — строковое представление результата в двоичной системе счисления.

**Пример использования:**
```python
print(to_binary_string(10))
print(to_binary_string(5))
print(to_binary_string(0))
```
**Результат:**
```
0101
101
0
```

**Алгоритм работы:**
1. Создаётся пустой список для хранения двоичных цифр.
2. Пока число больше нуля, вычисляется остаток от деления на два.
3. Полученный остаток добавляется в список.
4. Число делится на два с округлением вниз.
5. После завершения цикла проверяется значение счётчика `iterations`.
6. Если счётчик превышает 10, список разворачивается.
7. Список преобразуется в строку. Если список пустой — возвращается `"0"`.

**Важное замечание:** реализация имеет особенность — двоичные цифры записываются в обратном порядке. При стандартном значении `iterations=0` результат для числа 10 будет `"0101"`, а не `"1010"`. Для числа 5 результат будет `"101"`, что совпадает с ожидаемым представлением случайно.

Кроме того, при `iterations > 10` список разворачивается, а не инвертируется побитово. Параметр `iterations` также увеличивается внутри цикла, поэтому итог зависит от количества выполненных итераций.

Для стандартного преобразования числа в двоичную строку можно использовать встроенную функцию:
```python
def to_binary_string(number):
    return bin(number)[2:]
```
Примечание: этот вариант рассчитан на неотрицательные целые числа.
