# Лабораторная 4 ИСУ 414791

Дополнительные unit-тесты модуля кофейни. Основной вариант работы — [тесты API через Bruno](../testing/README_414791.md).

Исходный пример `test_coffe.py` заменил на `test_coffee.py`: старый импортировал отсутствующие функции и содержал повторяющееся имя теста.

## Запуск

Нужен Python 3, дополнительных пакетов нет. Из корня репозитория:

```sh
python -m unittest discover -s Coffee -p test_coffee.py -v
```

Или из папки `Coffee`:

```sh
python -m unittest test_coffee.py -v
```

53 теста: все проходят. До исправлений проходило 27, было 16 сбоев проверок и 10 ошибок.

## Проверки

Все пять функций `coffee.py`, обычные входные данные, нули, отрицательные значения, неверные типы, пустое меню, формат чека, длину и состав пароля. Отдельно проверил импорт без вывода.

Количество - целое число от нуля, цена - конечное число от нуля. `bool` не считается количеством или ценой. Ошибочные данные вызывают `ValueError`. Пароль может быть длиннее 8 символов, как предусматривал исходный параметр `length`.
